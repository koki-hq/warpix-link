# WARPIX LINK（ワーピックス・リンク）

**よく行くリンクを、グループにまとめてひらく。**

よく行く リンクを グループに まとめて、ワンタップで ひらける **リンクアプリ** です。ドット絵の ナビゲーター「ピクセ」が いつも 画面の うえで まっています。
ピクセルアート・レトロゲーム・チップチューンの 見た目は そのまま、[WARPIX製作所](https://warpix.app/) の 第一弾です。

なまえ：文字では **WARPIX LINK**、ロゴは WARPIX-LINK、読みは ワーピックス・リンク、ハッシュタグは #WARPIXLINK。ホーム画面の アイコンの 下は WARPIX。`warpix-link`（リポジトリ）と `link.warpix.app`（アドレス）は 中の なまえです。
ビルド不要の素の HTML / CSS / JavaScript だけで動きます。

v2.0（2026-11）で、ピクセの へやや ゲームなどの お遊びを 引き算して、リンクアプリに しぼりました（「ひとつの アプリに、目的は ひとつ」）。v1 の 全部入りは 非公開の バックアップ リポジトリに のこして います。

## 特徴

- **1 画面**：iPhone で スクロール なし。うえから メニュー・おしらせ・＋、ロゴ、ピクセと ふきだし、グループの タブ、リンク（2 列 × 6 段、1 グループ 12 こ まで）
- **グループ**：タブは カセット（下の かどを ななめに きった かたち・ラベルに なまえ・えらんで いる ものは 金で 背が たかく リールの まど）。リンクの ならぶ ばしょの すぐ 下に グループの てんてん（いま いる ところが 金、いちは いつも おなじ）、下の すきまを よこに スワイプしても きりかえ。タブの ＋ は ワンタップで「ぐるーぷ1」の ように すぐ できる。右上の ＋ は なまえを 入れて つくる（から なら「ぐるーぷN」・12 もじ まで）。99 こ まで（達したら まんなかの まどで しらせる）。タブ（えらんで いる ものは 金で ぬる・おおい ときは よこに スクロール）か よこ スワイプで きりかえ。グループが ない ときは「あなただけの空間を作ろう」
- **リンクを 追加**：「じぶんで つくる」が さき（コピーの しかたの ひとこと つき、「はりつける」で コピーした アドレスを 1 かいで。なまえと アイコンも アドレスから きめる）と「リストから えらぶ」（49 この 公式リンク、おすと 追加・もう いちど おすと とりけし）と「じぶんで つくる」（なまえ 16 もじ まで・https の アドレス・アイコン、99 こ まで）。作った リンクは「じぶんで つくる」の 下の 一覧から おして ほかの グループにも 追加。ながい なまえは 文字を ちいさく
- **へんしゅう ちゅう**：リンクを 長押しで はいる。ゆらゆら・左上の ✕ で はずす・つかんで ならべかえ・つかんだ まま 画面の 左右の はしで とまると となりの グループへ うつせる・じぶんの リンクを おすと まんなかの まどで へんしゅう（なまえ・アドレス・アイコン、リストの リンクは「かえられないよ」と しらせる だけ）・「＋ リンクを 追加」も そのまま つかえる。上の おびの「おわる」で もどる
- **グループの へんしゅう**：えらんで いる タブ（✎）を もう いちど おすと、なまえ・リンクの ならべかえ・はずす・グループの じゅんばん・けす
- **ピクセ**：あいさつ（なれた 人ほど みじかく、ひさしぶりなら「おぼえてるよ」、その 日 はじめては ときどき きせつ・ようびの ひとこと）、つつくと いまの けしき（まち・おか・ゆうやけ）の ひとことも・つづけて つつくと「もう、わかった わかった。」、きせかえ・いろ を かえた とき 1 かい だけ ひとこと、はりつけると「ぺたっ。」、はじめは「グループを つくる」まで 案内、つかいかたの ひとことは 1 かい だけ、つつくと ひとこと、リンクに カーソルで 行き先の しょうかい、いっしょに ワープして おみやげばなし、ときどき UFO
- **季節の 衣装**：ハロウィン・クリスマス・おしょうがつ・たなばた の 日に 自動で きがえる
- **空**：メニューの「きせかえ」で ひる・ゆうがた・よる。ながれる 星と ドットの くも、その日の かたちの 月。画面の 下に ドットの ちへいせん（まち・おか・なし、よるは まどの あかりが ときどき かわる）。きせつの そら（12〜2 月 ゆき・3〜4 月 はなびら・7〜8 月 はなび・10〜11 月 おちば）
- **リンクの がら・いろ**：ブロック（あつみの ある 立体、押すと しずむ）か ネオン（ひかる せん）を きせかえ で。アイコンの いろは みずいろ・ピンク・きいろ・みどり・しろ（リストの リンクも いろ だけ かえられる、ネオンは ふちも その いろ）
- **はいけい**：ひる・ゆうがた・よる＋じぶんの がぞう 9 まいまで（トリミングして、この ブラウザの なか だけに ほぞん。読みこみに じかんが かかる ときは ピクセが ぴょんぴょん）。メニューは 全部の グループ 共通、グループの へんしゅうの スイッチを ON に すると そのグループだけ。がぞうは メニューと グループで おなじ 一覧
- **メニュー**：きせかえ（そら・ちへいせん・リンクの がら、ひらくと まず ここ）・おと（BGM と 効果音の オン オフ・おおきさ）・きろく（どこに なんかい ワープしたか、日・週・月・年・ぜんぶ（日付つき）、◀ ▶ で 前の 日・週・月・年へ、ようびごと）・ひっこし（データの ひっこし コード）・アプリ（この アプリに ついて・ピクセに おてがみ）
- **おしらせ**：右上の ふうとう。WARPIX製作所からの おしらせ
- **ホーム画面に 追加**（名前は WARPIX LINK。ブラウザで ひらいて いる スマホの 人には、はじめて リンクを 入れた とき と 5 かい ひらく ごとに さそう）・オフラインでも ひらける（サービスワーカー）。新しい 版が とどくと「新しいバージョンがあります」
- **ぜんぶ この ブラウザの なか**：グループ・リンク・きろく・せっていは どこにも おくらない。きた ひとの かず だけ Cloudflare で かぞえる

## 見かた

`index.html` をブラウザで開くだけで動きます。ローカルサーバーで見たい場合は、たとえば `python3 -m http.server` 。

- `?date=2026-12-24` のように 付けると、その日の ページ（季節の 衣装・月の かたち）になります
- `?go=manual` で だれでも せつめいしょ から ひらきます

## テストと健康診断

```sh
node tests/run.mjs            # ぜんぶの テスト（77 件。あいて いる メモリで 2〜5 つ 同時に）
node tests/run.mjs links      # 名前に links を含むテストだけ
node tools/health.mjs         # 重さ・スマホでの速さ・待機中の CPU・アクセシビリティ
node tools/fonts.mjs          # セリフや 文章に あたらしい 文字を つかったら
```

Node 22 以上と Chrome があれば動きます（ライブラリのインストールは不要。Chrome が見つからないときは環境変数 `CHROME_PATH`）。音は鳴らしません。

## 公開するとき

- `sw.js` の先頭にある `VERSION` を上げる（例：`warpix-v2.0.0` → `warpix-v2.0.1`）。上げないと、アプリやオフライン用に保存された古いファイルが使われ続けます
- 新しいファイルを足したら、`sw.js` の `FILES` にも足す
