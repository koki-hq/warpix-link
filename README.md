# WARPIX LINK（ワーピックス・リンク）

**よく行くリンクを、グループにまとめてひらく。**

よく行く リンクを グループに まとめて、ワンタップで ひらける **リンクアプリ** です。ドット絵の ナビゲーター「ピクセ」が いつも 画面の うえで まっています。
ピクセルアート・レトロゲーム・チップチューンの 見た目は そのまま、[WARPIX製作所](https://warpix.app/) の 第一弾です。

なまえ：文字では **WARPIX LINK**、ロゴは WARPIX-LINK、読みは ワーピックス・リンク、ハッシュタグは #WARPIXLINK。ホーム画面の アイコンの 下は WARPIX。`warpix-link`（リポジトリ）と `link.warpix.app`（アドレス）は 中の なまえです。
ビルド不要の素の HTML / CSS / JavaScript だけで動きます。

v2.0（2026-11）で、ピクセの へやや ゲームなどの お遊びを 引き算して、リンクアプリに しぼりました（「ひとつの アプリに、目的は ひとつ」）。v1 の 全部入りは 非公開の バックアップ リポジトリに のこして います。

## 特徴

- **1 画面**：iPhone で スクロール なし。うえから メニュー・おしらせ・＋、ロゴ、ピクセと ふきだし、グループの タブ、リンク（2 列 × 6 段、1 グループ 12 こ まで）
- **グループ**：右上の ＋ か タブの ＋ で つくる（なまえ ひっす・12 もじ まで）。かずの せいげん なし。タブ（えらんで いる ものは 金で ぬる・おおい ときは よこに スクロール）か よこ スワイプで きりかえ。グループが ない ときは「あなただけの空間を作ろう」
- **リンクを 追加**：「リストから えらぶ」（49 この 公式リンク、おすと 追加・もう いちど おすと とりけし）と「じぶんで つくる」（なまえ 16 もじ まで・https の アドレス・アイコン、18 こ まで）。ながい なまえは 文字を ちいさく
- **へんしゅう**：えらんで いる タブ（✎）を もう いちど おすと、なまえ・リンクの ならべかえ・はずす・グループの じゅんばん・けす
- **ピクセ**：あいさつ（なれた 人ほど みじかく、ひさしぶりなら「おぼえてるよ」）、はじめは「グループを つくる」まで 案内、つかいかたの ひとことは 1 かい だけ、つつくと ひとこと、リンクに カーソルで 行き先の しょうかい、いっしょに ワープして おみやげばなし、ときどき UFO
- **季節の 衣装**：ハロウィン・クリスマス・おしょうがつ・たなばた の 日に 自動で きがえる
- **空**：メニューの「はいけい」で ひる・ゆうがた・よる。ながれる 星と ドットの くも、その日の かたちの 月
- **メニュー**：きろく（どこに なんかい ワープしたか、1にち・1しゅう・1かげつ・ぜんぶ、◀ ▶ で 前の 日・週・月へ、ようびごと）・はいけい・おと（BGM と 効果音の オン オフ・おおきさ）・ひっこし（データの ひっこし コード）・アプリ（この アプリに ついて・ピクセに おてがみ）
- **おしらせ**：右上の ふうとう。WARPIX製作所からの おしらせ
- **ホーム画面に 追加**（名前は WARPIX LINK）・オフラインでも ひらける（サービスワーカー）。新しい 版が とどくと「新しいバージョンがあります」
- **ぜんぶ この ブラウザの なか**：グループ・リンク・きろく・せっていは どこにも おくらない。きた ひとの かず だけ Cloudflare で かぞえる

## 見かた

`index.html` をブラウザで開くだけで動きます。ローカルサーバーで見たい場合は、たとえば `python3 -m http.server` 。

- `?date=2026-12-24` のように 付けると、その日の ページ（季節の 衣装・月の かたち）になります
- `?go=manual` で だれでも せつめいしょ から ひらきます

## テストと健康診断

```sh
node tests/run.mjs            # ぜんぶの テスト（41 件。あいて いる メモリで 2〜5 つ 同時に）
node tests/run.mjs links      # 名前に links を含むテストだけ
node tools/health.mjs         # 重さ・スマホでの速さ・待機中の CPU・アクセシビリティ
node tools/fonts.mjs          # セリフや 文章に あたらしい 文字を つかったら
```

Node 22 以上と Chrome があれば動きます（ライブラリのインストールは不要。Chrome が見つからないときは環境変数 `CHROME_PATH`）。音は鳴らしません。

## 公開するとき

- `sw.js` の先頭にある `VERSION` を上げる（例：`warpix-v2.0.0` → `warpix-v2.0.1`）。上げないと、アプリやオフライン用に保存された古いファイルが使われ続けます
- 新しいファイルを足したら、`sw.js` の `FILES` にも足す
