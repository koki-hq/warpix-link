# warpix-link

ピクセルアート・レトロゲーム・チップチューンの雰囲気でまとめた、1ページのリンク集です。
ビルド不要の素の HTML / CSS / JavaScript だけで動きます。

## 特徴

- **PRESS START 画面**：クリックか Enter でスタートし、起動ジングルが鳴ってページが立ち上がる
- **起動アニメーション**：タイトルが落ちてきて、リンクボタンが1つずつ出てくる（`steps()` でカクカク動く）
- **流れる星**：背景に canvas で描いたドットの星が縦スクロールで流れる
- **ドット絵アイコン**：12×12 マスのアイコンを JS の文字列から SVG にして表示
- **チップチューン BGM**：Web Audio API で鳴らす4小節ループ。右上のボタンで ON/OFF でき、設定はブラウザに保存される
- **効果音**：ボタンにマウスを乗せたとき・クリックしたときに 8bit 風の音が鳴る
- **ナビゲーター「ピクセ」**：RPG 風のメッセージウィンドウでしゃべるマスコット。つつくとジャンプしてコインが出る
- **スコア**：リンク +100、ピクセ +10、UFO +1000。ハイスコアはブラウザに保存される
- **ワープ演出**：リンクを押すと星が光の筋になって加速し、画面がゆれる
- **UFO**：20〜40秒ごとに空を横切る。クリックで撃ち落とせる
- **隠し要素**：ひみつの方法でワープゾーンが開く（答えは下の「ネタバレ」）
- **ポーズ**：タブを切り替えると BGM が止まり、タブ名に PAUSE が付く
- **ミニゲーム「PIXE INVADERS」**：いちばん下の INSERT COIN で始まるインベーダー風ゲーム。ゲームボーイと同じ 160×144 で描画。3 ウェーブごとに ボスの マザーシップが出る。ベスト 5 に入ると 3 文字の名前を入れられる。取った点はページのスコアにも入る
- **実績（57個）**：条件を満たすと ACHIEVEMENT UNLOCKED が出る。左上のトロフィーから一覧とヒントを見られる。ブラウザに保存される
- **隠しコマンド**：キーボードで英単語を打つと何かが起きる。スマホでは実績画面の CHEAT CODE 欄から
- **マザーシップ**：UFO を3機落とすと、HP 付きの巨大 UFO がやってくる
- **流れ星**：ときどき流れる。つかまえると +500 と、ピクセのひとこと
- **コンボ**：1.5秒以内に続けて点を取るとコンボ。5コンボごとに倍率が上がる（最大 x4）
- **ピクセのくらし**：時間帯であいさつが変わる。40秒ほうっておくと寝る。リンクにカーソルを乗せると行き先を紹介してくれる
- **キラキラ**：マウスを動かすとドットのキラキラが残る
- **開発者ツール**：コンソールを開くとメッセージがある
- **PIXE ADVENTURE**：ピクセが箱から飛び出して、**本物のリンクボタンやタイトルを足場に**ページの上を跳びまわるアクション。コイン8枚を集めてタイトルの上のゴールへ。タッチ端末では操作ボタンが出る
- **スタッフロール**：冒険をクリアすると、あなたの記録入りのエンディングが流れる
- **タブをこえるピクセ**：このページを2つのタブで開くと、ピクセどうしが気づく。ダブルクリックでとなりのタブへ遊びに行く
- **生きているファビコン**：タブのアイコンでもピクセがまばたきする。寝る、留守にする、お客さんが来ると「!」
- **本物の月**：右上の月は、その日の本当の月齢で欠けている
- **印刷すると認定証**：このページを印刷すると、ピクセ公認の認定証が出てくる
- **デモプレイ**：ピクセが寝たあとも放っておくと、ゲームセンターの筐体のようにミニゲームが勝手に遊ばれる
- **きせかえ**：実績のごほうびで、ピクセに帽子をかぶせられる（6種類）。WARDROBE の「＋ ぼうしを つくる」で、16×6 マスに じぶんで ぼうしを かいて かぶせられる（ファビコンや ポストカードにも でる）
- **ピクセが気づく**：何回目の来訪か、タブを離れていた時間、コピー、CAPS LOCK、窓のせまさなどに反応する
- **季節イベント**：ハロウィン（コウモリとかぼちゃ）、クリスマス（雪とジングルベル）、お正月（年賀状）、七夕（天の川）。日付でページが勝手に変わる
- **本物の天気**：ピクセが聞いてから、今いる街の天気をページに降らせる（雨ならピクセがかさをさす）
- **アプリになる**：ホーム画面に追加すると、ピクセのアイコンのアプリになる。オフラインでも開ける
- **コントローラー**：ゲームのコントローラーで、リンク選び・ミニゲーム・冒険・コナミコマンドまで全部遊べる
- **ほかの訪問者と同じ空**：いま見ているほかの人のピクセが空に浮かぶ。手を振れる。世界中でつつかれた回数も出る（設定したときだけ）
- **ピクセが育つ**：来てくれた日数で、スカーフ → マント → きんの アンテナ → でんせつ と育つ。しばらく来ないとすねて、久しぶりだと大喜び。記念日も覚えている
- **ピクセの日記**：左上の DIARY から、ピクセがつけている「ふたりの日記」が読める（このブラウザの中だけに保存）
- **みんなでマザーシップ**：5 分おき（0・5・10…分ちょうど）に、そのとき見ている全員の空へ同じマザーシップが来る。HP はみんなで共有、60 秒以内にみんなで倒す
- **シンプルモード**：リンクだけを静かに見たい人のために。スタート画面の「リンクだけ みる」、右上の SIMPLE、または URL に `?simple=1`
- **お気に入りのリンク**：よく行くリンクにはハートが付き、ピクセが 1 日 1 回「きょうも いく？」とそっと勧める（2 回断れば 1 週間は聞かない）
- **ピクセと さっきょく**：右上の ♪ で、ドットのピアノロールに音を置いて自分のチップチューンを作り、BGM にできる。曲は URL にして人に送れる
- **ピクセの おみくじ**：フッターから 1 日 1 回。運勢とラッキーリンク・ラッキーカラー
- **冒険のゴースト**：毎日ちがう「きょうのコース」。その日のベストの走りが半透明のゴーストになっていっしょに走る
- **ピクセの ずかん**：日記のノートの「ずかん」タブに、空で出会ったもの・見た月・天気・季節・おみくじ・帽子が集まっていく（まだのものはシルエット）
- **ピクセの こえ**：「せってい」で オンに すると、ピクセが セリフを こえに だして しゃべる（ブラウザの よみあげ。にほんごの こえを たかめに）
- **きゅうけい**：つづけて 50 ぷん あそぶと、ピクセが「めを やすめない？」。「やすむ」で 20 びょう、いっしょに とおくを みる
- **アプリの ショートカット**：ホーム画面に いれた アイコンを ながおしすると、ミニゲーム・さっきょく・おみくじへ すぐ（`?go=game` など）
- **ピクセの ゆめ**：ほうっておいて ピクセが ねむると、あたまの うえに ゆめの ふきだし。さいきん いっしょに した こと（ボス・きょく・ぼうけん・UFO・ランキング・よく行く リンク）が ゆめに でる。おこすと「……◯◯ ゆめ なんて みてないってば。」
- **スタンプカード**：ノートの「スタンプ」タブに、あえた ひの カレンダー。その日の できごとで スタンプが かわる（おみやげ・ボス・ランキング・ぼうけん・おんがく・UFO）。れんぞく日数も
- **ピクセの おるすばん**：3 時間いじょう るすにして もどると、ピクセが るすばん中に クレヨンで かいた え と、つくった きょくを くれる（え は保存でき、きょくは たなに しまえる）
- **ピクセの ガイド**：2 日目から、あいさつの最後に「きょうの ヒント」を 1 日 1 つ（まだ使っていない機能だけ）
- **じかんの そら**：空の色が本物の時刻でゆっくり変わる（あさやけ・ひる・ゆうやけ・よる）
- **ピクセの ポストカード**：ノートの「ポストカード」で、いまのピクセ（姿・帽子・日記の 1 行・記録）をドット絵のはがき画像にして保存・共有
- **せってい**：フッターから。BGM と効果音の音量、うごきを へらす、よみやすい もじ、キー操作の一覧
- **このページについて**：フッターから、保存するもの・送るものの説明と「きろくを ぜんぶ けす」
- **アクセシビリティ**：OS で「動きを減らす」を設定していると、星や雪は止まり、アニメーションはすぐ終わる。UFO・流れ星・ピクセの雨・キラキラ・デモプレイ・稲妻も出ない。雷のときも画面は光らせない

## 見かた

`index.html` をブラウザで開くだけで動きます。
ローカルサーバーで見たい場合は、たとえば次のようにします。

```sh
npx serve .
# または
python -m http.server
```

フォントは Google Fonts（Press Start 2P / DotGothic16）から読み込みます。一度開けばサービスワーカーが保存するので、2回目からはオフラインでも表示できます（`file://` で開いたときを除く）。

### リンクだけで渡す

URL の最後に `?simple=1` を付けると、スタート画面も演出もない、リンクだけのページで開きます（例：`https://koki-hq.github.io/warpix-link/?simple=1`）。

### 好きな日のページを見る

URL に `?date=2026-10-31` のように付けると、その日のページになります。季節イベントの確認に使えます（例：`?date=2026-12-24` でクリスマス、`?date=2027-01-01` でお正月）。

`?hour=18` のように付けると、その時刻の空の色になります（例：`?hour=6` で朝焼け、`?hour=18` で夕焼け）。

## テストと健康診断

```sh
node tests/run.mjs            # ブラウザでぜんぶの遊びを試す（91 件。4 つ同時に ながして 約 5 分）
node tests/run.mjs sky        # 名前に sky を含むテストだけ
node tests/run.mjs --jobs 1   # 1 つずつ順番に（約 16 分。いちばん安定）
node tools/health.mjs    # 重さ・スマホでの速さ・待機中の CPU・アクセシビリティ
```

Node 22 以上と Chrome があれば動きます（ライブラリのインストールは不要。Chrome が見つからないときは環境変数 `CHROME_PATH`）。音は鳴らさず、本物の Supabase（世界の記録）にも触りません。くわしくは [docs/spec/v1.6.1.md](docs/spec/v1.6.1.md)。

## 公開するとき

- 公開する前に `node tests/run.mjs` がぜんぶ通ることを確かめる

- `sw.js` の先頭にある `VERSION` を上げる（例：`warpix-v1.4.0` → `warpix-v1.4.1`）。上げないと、アプリやオフライン用に保存された古いファイルが使われ続けます
- 新しいファイルを足したら、`sw.js` の `FILES` にも足す

## オンライン機能（ほかの訪問者と同じ空）を使う

[Supabase](https://supabase.com) の無料プランで動きます。`config.js` が空のままなら、この機能は動きません（ほかの機能はすべて使えます）。

1. Supabase でプロジェクトを作る
2. SQL Editor で次を実行する（世界の記録を数える表と、数を増やす関数）

   ```sql
   create table counters (id text primary key, value bigint not null default 0);
   insert into counters (id) values ('pokes'), ('warps'), ('ufos');
   alter table counters enable row level security;
   create policy "anyone can read" on counters for select using (true);

   create or replace function bump(counter text, n int default 1)
   returns bigint language sql security definer set search_path = public as $$
     update counters
        set value = value + greatest(1, least(n, 20))
      where id = counter and counter in ('pokes', 'warps', 'ufos')
     returning value;
   $$;
   grant execute on function bump(text, int) to anon;
   ```

3. Project Settings → API の **Project URL** と **anon（publishable）キー**を `config.js` に書く。どちらもブラウザに載せてよい公開用の値です。**`service_role` / `secret` キーは絶対に書かないこと**

送るのは、タブごとのランダムな番号と帽子の種類だけです。

## カスタマイズ

### リンクを変える・増やす

`index.html` の `<nav class="links">` の中に、1リンクにつき1つ `<a>` を書きます。

```html
<a class="pixel-btn" href="https://www.youtube.com/@yourname" target="_blank" rel="noopener">
  <span class="arrow">▶</span><span class="icon" data-icon="youtube"></span>YOUTUBE
</a>
```

- `href`：リンク先
- `data-icon`：使うアイコンの名前（`script.js` の `ICONS` のキー）
- 最後の文字：ボタンに表示する名前

出てくる順番のアニメーションは、並び順から自動で決まります。

### アイコンを描く・直す

`script.js` の `ICONS` に、12文字 × 12行で描きます。`#` が塗り、`.` が透明です。

```js
heart: [
  "............",
  "..##....##..",
  ".####..####.",
  // ...あと9行
],
```

色はボタンのアイコン色（`style.css` の `.pixel-btn .icon`）で決まります。

### 色を変える

`style.css` の先頭の `:root` にある変数を変えます。各色の役割は [docs/THEME.md](docs/THEME.md) にまとめています。

### BGM を変える

`script.js` の `sound` の中にある次の値を変えます。

- `BPM`：テンポ
- `LEAD`：メロディ。8分音符ごとの MIDI ノート番号（60 = 真ん中のド）、`null` は休符
- `BASS`：1小節ごとのベースの根音（MIDI ノート番号）

`LEAD` の長さを変えたら、`BASS` の数を「`LEAD` の長さ ÷ 8」に合わせてください。

### ピクセのセリフを変える

`script.js` の `npc` の中にある配列を書き換えます。`\n` で改行できます（ウィンドウは2行ぶん）。

- `INTRO`：スタート直後に順番にしゃべるセリフ。ウィンドウをクリックで次へ
- `CHATTER`：つついたときにランダムでしゃべるセリフ

ピクセの見た目は `NPC`（16×16、`idle` とまばたきの `blink` の2コマ）で、文字と色の対応は `PALETTE` です。

### ワープゾーンのリンク先を変える

`index.html` の `id="secret-link"` の `href` を変えます。

### 実績を足す

`extras.js` の `achievements` の `LIST` に1行足し、条件のところで `achievements.unlock("id")` を呼びます。

### 隠しコマンドを足す

`extras.js` の `cheats` の `COMMANDS` に、単語をキーにした関数を足します。キーボード入力と CHEAT CODE 欄の両方で使えるようになります。

## ネタバレ

### ワープゾーンの開き方

- キーボードで **↑ ↑ ↓ ↓ ← → ← → B A**
- スマホなどでは、**ピクセを10回つづけてつつく**（1.5秒以上あくとカウントがリセット）

### 隠しコマンド

| 単語 | 起きること |
| --- | --- |
| `gameboy` | ゲームボーイの4色になる（もう一度で戻る） |
| `party` | 10秒間パーティー。BGM が速くなり、星がカラフルに、ピクセが踊る |
| `pixe` | ピクセが24匹ふってくる。つかまえると +50 |
| `warp` | 3秒間のハイパーワープ |
| `help` | まだ取っていない実績のヒントをピクセが教えてくれる |
| `invaders` | ミニゲームを始める |
| `adventure` | PIXE ADVENTURE を始める |
| `credits` | スタッフロールを流す |
| `print` | 印刷（→ 認定証） |
| `weather` | 天気を調べていいか、もう一度聞いてくる |
| `install` | ホーム画面に追加する（できないときは、やり方を教えてくれる） |
| `diary` | ピクセの日記を開く |
| `compose` | 作曲画面を開く |
| `omikuji` | おみくじを引く |
| `zukan` | 図鑑をひらく |
| `settings` | せっていをひらく |
| `postcard` | ポストカードを作る |

### PIXE ADVENTURE の始めかた・操作

- 起動して25秒ほどたつと、ピクセが「そとに でてみたい」と聞いてくるので「いいよ！」。またはコマンド `adventure`
- ← → で移動、Space（↑ / W / Z）でジャンプ、↓ で足場から下りる、Esc でやめる
- 足場は下からすり抜けられる。UFO は上から踏むと倒せる

### タブをこえるピクセ

同じページをもうひとつのタブで開き、ピクセをダブルクリックすると、となりのタブへ遊びに行きます。お客さんのピクセをクリックすると帰ります。
