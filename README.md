# WARPIX LINK（ワーピックス・リンク）

**いつものアプリを、ちょっと楽しくひらく入口。**

いつもの 公式サイトへ、ピクセの いる 空間を とおって ワープする **踏み台リンク集** です。
ピクセルアート・レトロゲーム・チップチューンの雰囲気でまとめた 1 ページで、[WARPIX製作所](https://warpix.app/) の 第一弾です。

なまえ：文字では **WARPIX LINK**、ロゴは WARPIX-LINK、読みは ワーピックス・リンク、ハッシュタグは #WARPIXLINK。ホーム画面の アイコンの 下は WARPIX。`warpix-link`（リポジトリ）と `link.warpix.app`（アドレス）は 中の なまえです。
ビルド不要の素の HTML / CSS / JavaScript だけで動きます。

## 特徴

- **PRESS START 画面**：クリックか Enter でスタートし、起動ジングルが鳴ってページが立ち上がる。うえに ひとこと「いつものアプリを、ちょっと楽しくひらく入口。」
- **とりあつかい せつめいしょ**：はじめての 人にだけ、ひらいて すぐ 4 まい（これは なに？・つかいかた（ワープ）・リンクは じぶん好みに・ホーム画面に 入れよう。リンクは つかう ぜんてい）。ちいさな うごく え つき。ホーム画面の やりかたは ひらいて いる 場所で かわる（iPhone の Safari では ピクセが 画面の 下を ゆびさす、インスタや LINE の なかでは さきに ブラウザで ひらく）。とばせる・もどれる・いちど とじたら 出ない・前に 来た 人には 出ない。「このページについて」から よみなおせる。`?go=manual` の リンクを ひらくと だれでも せつめいしょから（おたより #4・#6 から）
- **オープニング**：PRESS START の あと、ほんものの ほしぞらの うえで 17 びょうの ものがたり（「ずっと とおくの ほしぞらに／だれも しらない ちいさな こうじょうが ありました。」→ WARPIX製作所の えんとつから ぽん → ワープ → ピクセの はこへ）。まだ みて いない 人に 1 かい、SKIP いつでも、「このページについて」か `?go=prologue` で もういちど
- **ピクセと であう だけの 日**：はじめての 日は、じかんや ほうって おいた ことの 実績・おしらせの ひかり・デモプレイを ださない。ねむる までも ながく。ピクセの セリフは よむ じかんを まってから つぎへ
- **セリフの じゅんばん**：ピクセが じぶんから はなしかける もの（おさそい・てんき・カードの よかん など）は、よみおわって すこし まを あけて、まどや ゲームの とちゅうでは まって から。あさの あいさつの「かるい わだい」（きせつ・ヒント など）は、だいじな はなしが すくない ひに 1 つ だけ
- **はやく ひらく**：config.js と cassette.js いがいの スクリプトは defer。おそい スマホの 回線でも 1.5 びょうで PRESS START が みえる（ファイルが そろう まえに おすと NOW LOADING...）
- **起動アニメーション**：タイトルが落ちてきて、リンクボタンが1つずつ出てくる（`steps()` でカクカク動く）
- **流れる星**：背景に canvas で描いたドットの星が縦スクロールで流れる
- **カセット えらび**：リンクは いつも 6 こ。リンクの したの「⇄ リンクの へんせい」→「リンクを いれかえる」で、たなに ならんだ 公式リンク（49 こ：SNS・おんがく・みる あそぶ・どうが サブスク・マンガ・つくる とどける・おかいもの・せいかつ・べんきょう。たなは たためる、いつもの と じぶんの リンク だけ ひらいて いる）から えらんで いれかえられる。パソコンでは 1〜6 の キーで その ばんごうの リンクへ ワープ（リンクの みぎはしに ちいさな ばんごう）。最初は いつもの 6 こ（YouTube・Twitter (X)・Instagram・BOOTH・Tumblr・Spotify）
- **じぶんの リンク**：たなの「じぶんの リンク」の「＋ つくる」で、なまえ（10 もじ）・`https://` の アドレス・よういした ドット絵の アイコン（12 しゅるい）を えらんで つくれる。18 こまで（パーティ 3 つ × 6 こ を ぜんぶ じぶんの リンクに できる）。みぎうえの えんぴつで なおす・けす（2 かい おし、パーティに はいって いたら そこは いつもの リンクに もどる）。この ブラウザの なか だけ（ユーザー登録 なし・おすそわけ なし）。アイコンを あいての サイトから とって こない。ピクセの ひとことは きょうつうの もの
- **パーティ**：6 この くみあわせを 3 つまで もてる。「リンクの へんせい」→「パーティを ふやす」で 6 こ ぜんぶ えらぶと できる（からっぽの パーティは つくれない）。2 つ いじょう ある ときだけ リンクの した（「リンクの へんせい」の うえ）に「◀ PARTY 1 ▶」が でて、じぶんで きりかえる（じかんで かわったり しない）。なまえは さいしょ PARTY 1・2・3 で、かえたい ひとだけ かえる。けす ときは 2 かい おし。さいごに つかった パーティを おぼえて おく
- **ドット絵アイコン**：12×12 マスのアイコンを JS の文字列から SVG にして表示
- **チップチューン BGM**：Web Audio API で鳴らす4小節ループ。右上のボタンで ON/OFF でき、設定はブラウザに保存される
- **効果音**：ボタンにマウスを乗せたとき・クリックしたときに 8bit 風の音が鳴る
- **ナビゲーター「ピクセ」**：RPG 風のメッセージウィンドウでしゃべるマスコット。つつくとジャンプしてコインが出る
- **スコア**：リンク +100、ピクセ +10、UFO +1000。ハイスコアはブラウザに保存される
- **ワープ演出**：リンクを押すと星が光の筋になって加速し、画面がゆれる
- **UFO**：20〜40秒ごとに空を横切る。クリックで撃ち落とせる
- **隠し要素**：ひみつの方法でワープゾーンが開く（答えは下の「ネタバレ」）。ワープゾーンの さきは アプリの なかの「ひみつの こうじょう」（せっけいずの ピクセ、いまの 版、ワープの かいすう。みたい ひと だけ「かくしコマンドを みる」で かくしコマンド集）
- **ポーズ**：タブを切り替えると BGM が止まり、タブ名に PAUSE が付く。もどった とき iPhone が タップを まって いれば、BGM ボタンが「BGM ♪z」に なって ピクセの あたまに「♪z」が うかび、どこを タップしても 音が もどる（ピクセが はねる）。iPhone は しくみ上 タップ なしでは 音を もどせない。Android や パソコンは もどった とき じどうで もどる。BGM は ほかの アプリの 音（Spotify など）の じゃまを しない（マナーモードでは 鳴らない）
- **ミニゲーム「PIXE INVADERS」**：いちばん下の INSERT COIN で始まるインベーダー風ゲーム。ゲームボーイと同じ 160×144 で描画。3 ウェーブごとに ボスの マザーシップが出る。ベスト 5 に入ると 3 文字の名前を入れられる。取った点はページのスコアにも入る
- **実績（67個）**：条件を満たすと ACHIEVEMENT UNLOCKED が出る。左上の ROOM（ピクセの おへや）の「じっせき」で一覧とヒントを見られる。ブラウザに保存される
- **隠しコマンド**：キーボードで英単語を打つと何かが起きる。スマホでは おへやの「じっせき」の CHEAT CODE 欄から
- **マザーシップ**：UFO を3機落とすと、HP 付きの巨大 UFO がやってくる
- **流れ星**：ときどき流れる。つかまえると +500 と、ピクセのひとこと
- **コンボ**：1.5秒以内に続けて点を取るとコンボ。5コンボごとに倍率が上がる（最大 x4）
- **ピクセのくらし**：時間帯であいさつが変わる。**なれ**：じこしょうかいと ボタンの せつめいは はじめての ときだけ。そのあとは あいさつ 1 ぎょうで、会った 日が ふえるほど くだけて いく（7 日から なかよし、ときどき とくべつな ひとこと）。おなじ 日に また 来たら「さっきぶり！」など。おなじ あいさつは 2 かい つづかない。来た かいすうは ふしめ（2・10・50・100 かいごと）だけ、ホーム画面の「アプリの ぼく、どう？」は はじめての ときだけ、てんきの ひとことは おなじ 日・おなじ 天気なら 1 かい（そらと かさは まいかい）、タブから もどった ときの「おかえり」は まいかい ちがう いいかた。40秒ほうっておくと寝る。リンクにカーソルを乗せると行き先を紹介してくれる
- **きた ひとの かず**（v1.65）：Cloudflare Web Analytics で、ひらかれた かずと、SNS の プロフィールの 入口（`/x/` `/ig/` `/tt/` `/yt/`、かぞえたら すぐ 本体へ）から きた かずを かぞえる。クッキー なし、だれかは わからない。トークンは `config.js` の `WARPIX_COUNT`（本番の ホストで だけ うごく）
- **キラキラ**：マウスを動かすとドットのキラキラが残る
- **開発者ツール**：コンソールを開くとメッセージがある
- **PIXE ADVENTURE**：ピクセが箱から飛び出して、**本物のリンクボタンやタイトルを足場に**ページの上を跳びまわるアクション。コイン8枚を集めてタイトルの上のゴールへ。タッチ端末では操作ボタンが出る
- **スタッフロール**：冒険をクリアすると、あなたの記録入りのエンディングが流れる
- **ピクセ RTA**：ぼうけんの コースは 日がわりで、その 日は だれでも おなじ（足場は 画面の 大きさで かわる）。クリアすると ピクセが「きろくカード」を つくるか きく。日付・タイム・ゴーストとの 差・じこベスト・おなじ そらの きょうの いちばん の はいった 画像を ほぞん・シェア（#ピクセRTA）。しゅうらいの よる（おなじ そらに つながって いる とき）だけ、タイムを おなじ そらの ひとに しらせあう
- **1きせいの きっぷ**：正式な 開店（2026-11-01 の 予定）より まえに はじめて きた ひとは「1きせい」。ピクセが きっぷを わたして、ROOM の かべに かざる きっぷ・ポストカード・ぼうけんの きろくカードに「★1きせい」。あとから きた ひとは もう もらえない（じっせきや ずかんには いれない）
- **開店の よる**：開店の 日（11/1）いこうに 1きせいが ひらくと、ピクセから「ひらく ひの てがみ」（1 かい だけ）。しゅうらいの よるに だい マザーシップを たおすと、そこに いた 人数ぶんの ほしで せいざが うかぶ（ほしの いろは みんなの ぼうし）。せいざは ROOM の WORLD RECORD に まいつき ふえていく。せいざの あと ピクセが「みんなで きねんしゃしん とろう！」── せいざの したに いっしょに たたかった みんなの ピクセ（それぞれの ぼうし、まんなかが じぶん）が ならぶ しゃしんを ほぞん・シェア（WORLD RECORD の せいざを おしても みられる）
- **WARPIX カード**：ピクセと きみの きねんひん。3 つの わく ── **ふしめ**（ワープの 1・10・100・500・1000 かいめ、かいすうで ランク。かずは プロフィールの「ワープした かず」と おなじ。すぎた ふしめは さかのぼって もらえる）・**ラッキー**（ふだんの ワープの かえりに きまぐれ。ピクセが「ポケットが ひかってる」と いったら でる かも。しろ・ぎん・きん・にじ は うん）・**とくべつな ひ**（きせつ・しゅうらいの よる・オープン きねん 2026/11/1〜7・しゅうねん まいとし 11/1〜7。ランクの そとの その ひ だけの デザイン）。ピクセの かおと ポーズは いつも おなじで、レアは せなかの けしき（ほしぞら → つきと ほしぐも → きんの ひかり → オーロラと ながれぼし）・わく・ホロ（ひかりの おびが ながれ、ゆびで なぞると ついて くる）で みせる。でる ときは うらむきで ひかりながら おちて きて、タップで めくると カードの したの ピクセが よろこぶ（音も レアで かわる）。ROOM の カードばこに コレクションの たな（No.01〜16、まだ ない ばんごうは うらむき）。カードを ひらくと「この カードを もっている ひと：ぜんたいの ○%」
- **ピクセの さとがえり**：2 日め いこう、ひらいて しばらく たって ピクセが ひまだと、1 日 1 かい「ちょっと うまれた こうじょうに あそびに いってくる！」と 30 びょう るすに（はこに「おでかけ」）。もどると WARPIX製作所（ホームページの 町工場）で きいてきた はなし（ヘルメットの ピクセ、ゲンさんの おべんとう、ソラマメ号 …）。にっきに のこる
- **ピクセに おてがみ**：「このページについて」の「ピクセに おてがみを かく」で、メールの アプリが pixe@warpix.app あてで ひらく（したがきに いまの 版と きかいの しゅるい）。アプリからは なにも おくらない
- **タブをこえるピクセ**：このページを2つのタブで開くと、ピクセどうしが気づく。ダブルクリックでとなりのタブへ遊びに行く
- **生きているファビコン**：タブのアイコンでもピクセがまばたきする。寝る、留守にする、お客さんが来ると「!」
- **本物の月**：右上の月は、その日の本当の月齢で欠けている
- **印刷すると認定証**：このページを印刷すると、ピクセ公認の認定証が出てくる
- **デモプレイ**：ピクセが寝たあとも放っておくと、ゲームセンターの筐体のようにミニゲームが勝手に遊ばれる
- **クローゼット**：おへやの ハンガーラックで「ぼうし」と「コスチューム」を 1 つずつ きせかえ。アイテムを おすと おおきな ピクセが ためしに きて、「これに する」で きまり。もらいかたは さいしょから（ベレーぼう・まるめがね）・あえた ひ（2 ねこみみ・3 スカーフ・5 リボン・7 マント・10 ヘッドホン・14 きんの アンテナ・20 オーバーオール・30 シルクハット・50 スーツ）・きせつ（あき・ふゆ・つゆ・なつ・クリスマス など）・じっせき。ベレーは 4 しょくから えらべる。あたらしく もらった ものが あると ハンガーラックが ひかり、その アイテムに NEW。コスチューム だけ あか・みどり・ちゃいろ・こん も つかう。「＋ ぼうしを つくる」で、16×6 マスに じぶんで ぼうしを かいて かぶせられる（ファビコンや ポストカードにも でる）
- **ピクセが気づく**：何回目の来訪か、タブを離れていた時間、コピー、CAPS LOCK、窓のせまさなどに反応する
- **季節イベント**：ハロウィン（コウモリとかぼちゃ）、クリスマス（雪とジングルベル）、お正月（年賀状）、七夕（天の川）。日付でページが勝手に変わる
- **本物の天気**：ピクセが聞いてから、今いる街の天気をページに降らせる（雨ならピクセがかさをさす）
- **アプリになる**：ホーム画面に追加すると、ピクセのアイコンのアプリになる。オフラインでも開ける。iPhone では 起動画面で ピクセが ねむっていて、ひらくと テレビの スイッチが はいる
- **ホームがめんに いれる**：「このページについて」の いちばん うえに、iPhone・Android・パソコンの いれかた。いまの きかいに「（この きかい）」の しるし。ブラウザが いれられる ときは「ホームがめんに いれる」ボタン。iPhone では Safari と アプリで きろくが べつ なので、じゅもんで もっていく ちゅうい
- **コントローラー**：ゲームのコントローラーで、リンク選び・ミニゲーム・冒険・コナミコマンドまで全部遊べる
- **ほかの訪問者と同じ空**：**しゅうらいの よる（21:00 の 10 分前から おわるまで）だけ** つながる。ふだんは だれも うかばない。いま見ているほかの人のピクセが空に浮かぶ（ひらいた まま 裏に いる 人は いったん きえる）。手を振れる（おなじ 人には 10 秒に 1 回、ピクセの おはなしには わりこまない）。世界中でつつかれた回数も出る（設定したときだけ）
- **であった ひの プレゼント**：あえた ひの かずで コスチュームが とどく（2 ねこみみ・3 スカーフ・5 リボン・7 マント・10 ヘッドホン・14 きんの アンテナ・20 オーバーオール・30 シルクハット・50 スーツ）。へやの ステータスに「つぎの プレゼント あと N にち」。なまえは ずっと ピクセ（v1.63 で「せいちょう」と だんかいの なまえは やめた）。30 にちで キラキラ。しばらく来ないとすねて、久しぶりだと大喜び。記念日も覚えている
- **ピクセの てがみ**：にちようの よる（19:30〜）、ROOM の ポストに、その しゅうの こと（あえた ひ・ワープ・じっせき）を かいた てがみが とどく。8 つうまで よみかえせる
- **ワープ ダイブ**：リンクを おすと、ピクセが リンクの はしに ひらいた ワープあなに とびこんで いっしょに いく（リンクは いつもどおり すぐ ひらく）。このタブに もどると あなから とびだして「ただいま！」と、むこうの せかいで ピクセが どう かんじたか。いった せかいの たなで あなの いろが かわる（ピクセが もって かえる おみやげは v1.52.1 で やめた）

- **ピクセの つぶやき**：おへやの まどに、ピクセが 1 日 1 こ つぶやく（「100えんだま ひろった！ …と おもったら ボタンだった。」など 60 こ ＋ ハロウィンや おしょうがつ などの きまった 日）。その 日の つぶやきは みんな おなじ。こなかった 日の ぶんも さいきん 7 にち よめる。こちらが なにを したかは かかない。よんで いない 日は ROOM に NEW
- **しゅうらいの よる**：まいつき さいしょの にちようびの 21:00（日本時間）だけ、そのとき見ている全員の空へ 同じ きんいろの だい マザーシップが来る。HP はみんなで共有、3 ぷん いないに みんなで倒す。その 日に ひらくと ピクセが 予告する。ふだんは 来ない（v1.50 までは 10 分おきにも 来ていたが、リンクに かぶさって じゃま なので やめた。月 1 かい だから お祭りに なる）
- **シンプルモード**：リンクだけの 静かな ページ。入口は かくしコマンド `simple`（または URL に `?simple=1`）だけ。もどるは 右上の「▶ あそぶ」
- **ワープした かず**：リンクに いった かずを このブラウザの なかだけで かぞえる。おへやの ステータスに「ワープした かず」。ピクセは すすめない（よく いく リンクの ハートは v1.52.1 で やめた）
- **ピクセの おさそいは 1 かいに 1 つ**：ピクセの ほうから 話しかけるのは、1 かい ひらいて 1 つ まで（10 ぷん いじょう はなれて もどったら また 1 つ）。はじめての 日は じこしょうかい だけ。ぼうけん・ホーム画面・てんきの おさそいは、こたえたら 1 しゅうかん きかず、2 かい ことわられたら もう きかない
- **ピクセと さっきょく**：おへやの レコードプレーヤーで、ドットのピアノロールに音を置いて自分のチップチューンを作り、BGM にできる。曲は URL にして人に送れる
- **ピクセの おみくじ**：フッターから 1 日 1 回。運勢とラッキーカラー（v1.52 で ラッキーリンクは やめた。行き先に 口を ださない）
- **冒険のゴースト**：毎日ちがう「きょうのコース」。その日のベストの走りが半透明のゴーストになっていっしょに走る
- **ピクセの ずかん**：おへやの ほんだなに、空で出会ったもの・見た月・天気・季節・おみくじ・帽子が集まっていく（まだのものはシルエット）
- **かくれピクセ**：まいにち 3 びきの ちびピクセが、ページの どこかから のぞいている（ばしょは 日ごとに かわる）。みつけると 50 てん、ぜんぶで 実績
- **ピクセの こえ**：「せってい」で オンに すると、ピクセが セリフを こえに だして しゃべる（ブラウザの よみあげ。にほんごの こえを たかめに）
- **きゅうけい**：`rest` と うつと、20 びょう ピクセと いっしょに とおくを みる（ピクセの ほうからは すすめない）
- **アプリの ショートカット**：ホーム画面に いれた アイコンを ながおしすると、ミニゲーム・さっきょく・おみくじへ すぐ（`?go=game` など）
- **ピクセの ゆめ**：ほうっておいて ピクセが ねむると、あたまの うえに ゆめの ふきだし。さいきん いっしょに した こと（ボス・きょく・ぼうけん・UFO・ランキング・よく行く リンク）が ゆめに でる。おこすと「……◯◯ ゆめ なんて みてないってば。」
- **スタンプカード**：おへやの カレンダーに、あえた ひの カレンダー。その日の できごとで スタンプが かわる（ボス・ランキング・ぼうけん・おんがく・UFO）。れんぞく日数も
- **ピクセの ガイド**：2 日目から、あいさつの最後に「きょうの ヒント」を 1 日 1 つ（まだ使っていない機能だけ）
- **じかんの そら**：空の色が本物の時刻でゆっくり変わる（あさやけ・ひる・ゆうやけ・よる）
- **ピクセの ポストカード**：おへやの カメラで、いまのピクセ（姿・帽子・日記の 1 行・記録）をドット絵のはがき画像にして保存・共有
- **せってい**：フッターから。BGM と効果音の音量、うごきを へらす、よみやすい もじ、キー操作の一覧
- **このページについて**：フッターから、保存するもの・送るものの説明と「きろくを ぜんぶ けす」
- **きろくを まもる・ひっこす**：「このページについて」で **ふっかつの じゅもん**（きろくを ぜんぶ ちぢめた もじ）を コピー・ファイルに ほぞん。べつの ブラウザで いれると そっくり ひっこせる。ブラウザに「けさないで」とも おねがいする。3 日 あった ころ、ピクセが いちどだけ「ぼくの きおくは この ブラウザの なかに……」
- **ピクセの ひっこし**：じゅうしょが `link.warpix.app` に かわった（2026-10-18）。ふるい じゅうしょ（koki-hq.github.io/warpix-link）を ひらくと、あたらしい おうちが できていれば ピクセが「きろくごと ひっこす」と さそう。おすと きろくを じゅもんに して あたらしい じゅうしょへ はこぶ（どこにも おくらない）。あたらしい ほうに もう きろくが あれば きいてから
- **製作所の 名札**：フッターの いちばん下に「© 2026 WARPIX製作所」。WARPIX製作所の 製品だと ひとめで わかる
- **おしらせ**：みぎうえの ふうとうに、WARPIX製作所からの おしらせが とどく（あたらしい きのう・コスチュームの 入庫・開店 など）。けんめいの いちらん → ひらくと しょうさい、よんで いない ものが あると ふうとうが きんいろ。WARPIX LINK の なか だけで おわる（どこにも よみに いかない）。ホームページの 製作所だよりとは べつ。きせつの コスチュームが はいると その きせつの さいしょの ひに とどく。あとから きた ひとには それより まえの おしらせは とどかない
- **アクセシビリティ**：OS で「動きを減らす」を設定していると、星や雪は止まり、アニメーションはすぐ終わる。UFO・流れ星・ピクセの雨・キラキラ・デモプレイ・稲妻も出ない。雷のときも画面は光らせない

## オンライン機能（ほかの訪問者と同じ空）を使う

[Supabase](https://supabase.com) の無料プランで動きます。`config.js` が空のままなら、この機能は動きません（ほかの機能はすべて使えます）。

1. Supabase でプロジェクトを作る
2. SQL Editor で次を実行する（世界の記録を数える表と、数を増やす関数）。v1.53 の WARPIX カードの「もっている ひと ○%」には、そのあとに もう 1 つ（下の「カードの かず」）

   ```sql
   create table counters (id text primary key, value bigint not null default 0);
   insert into counters (id) values ('pokes'), ('warps'), ('ufos');
   alter table counters enable row level security;
   create policy "anyone can read" on counters for select using (true);

   create or replace function bump(counter text, n int default 1)
   returns bigint language sql security definer set search_path = public as $$
     update counters
        set value = value + greatest(1, least(n, 20))
      where id = counter and counter in ('pokes', 'warps', 'ufos')
     returning value;
   $$;
   grant execute on function bump(text, int) to anon;
   ```

   カードの かず（v1.53）：はじめて ひらいた ブラウザの かず（players）と、カードの ばんごうごとの かず（card-01〜999）。はじめて きた ばんごうは 行を じぶんで つくるので、カードを たしても SQL は いらない

   ```sql
   create or replace function bump(counter text, n int default 1)
   returns bigint language sql security definer set search_path = public as $$
     insert into counters (id, value)
     select counter, greatest(1, least(n, 20))
      where counter in ('pokes', 'warps', 'ufos', 'players') or counter ~ '^card-[0-9]{2,3}$'
     on conflict (id) do update set value = counters.value + excluded.value
     returning value;
   $$;
   ```

3. Project Settings → API の **Project URL** と **anon（publishable）キー**を `config.js` に書く。どちらもブラウザに載せてよい公開用の値です。**`service_role` / `secret` キーは絶対に書かないこと**

送るのは、タブごとのランダムな番号と帽子の種類だけです。

## カスタマイズ

### リンクを変える・増やす

`index.html` の `<nav class="links">` の中に、1リンクにつき1つ `<a>` を書きます。

```html
<a class="pixel-btn" href="https://www.youtube.com/@yourname" target="_blank" rel="noopener">
  <span class="arrow">▶</span><span class="icon" data-icon="youtube"></span>YOUTUBE
</a>
```

- `href`：リンク先
- `data-icon`：使うアイコンの名前（`script.js` の `ICONS` のキー）
- 最後の文字：ボタンに表示する名前

出てくる順番のアニメーションは、並び順から自動で決まります。

### アイコンを描く・直す

`script.js` の `ICONS` に、12文字 × 12行で描きます。`#` が塗り、`.` が透明です。

```js
heart: [
  "............",
  "..##....##..",
  ".####..####.",
  // ...あと9行
],
```

色はボタンのアイコン色（`style.css` の `.pixel-btn .icon`）で決まります。

### 色を変える

`style.css` の先頭の `:root` にある変数を変えます。各色の役割は [docs/THEME.md](docs/THEME.md) にまとめています。

### BGM を変える

`script.js` の `sound` の中にある次の値を変えます。

- `BPM`：テンポ
- `LEAD`：メロディ。8分音符ごとの MIDI ノート番号（60 = 真ん中のド）、`null` は休符
- `BASS`：1小節ごとのベースの根音（MIDI ノート番号）

`LEAD` の長さを変えたら、`BASS` の数を「`LEAD` の長さ ÷ 8」に合わせてください。

### ピクセのセリフを変える

`script.js` の `npc` の中にある配列を書き換えます。`\n` で改行できます（ウィンドウは2行ぶん）。

- `INTRO`：スタート直後に順番にしゃべるセリフ。ウィンドウをクリックで次へ
- `CHATTER`：つついたときにランダムでしゃべるセリフ

ピクセの見た目は `NPC`（16×16、`idle` とまばたきの `blink` の2コマ）で、文字と色の対応は `PALETTE` です。

### ワープゾーンのリンク先を変える

`index.html` の `id="secret-link"` の `href` を変えます。

### 実績を足す

`extras.js` の `achievements` の `LIST` に1行足し、条件のところで `achievements.unlock("id")` を呼びます。

### 隠しコマンドを足す

`extras.js` の `cheats` の `COMMANDS` に、単語をキーにした関数を足します。キーボード入力と CHEAT CODE 欄の両方で使えるようになります。

### PIXE ADVENTURE の始めかた・操作

- 起動して25秒ほどたつと、ピクセが「そとに でてみたい」と聞いてくるので「いいよ！」。またはコマンド `adventure`
- ← → で移動、Space（↑ / W / Z）でジャンプ、↓ で足場から下りる、Esc でやめる
- 足場は下からすり抜けられる。UFO は上から踏むと倒せる

### タブをこえるピクセ

同じページをもうひとつのタブで開き、ピクセをダブルクリックすると、となりのタブへ遊びに行きます。お客さんのピクセをクリックすると帰ります。
