# warpix-link テーマ

## コンセプト

**「リンクを選ぶと、別の世界へワープする」レトロゲームのステージセレクト画面。**

夜空を流れる星の中で、ゲーム機の電源を入れたときのように PRESS START から始まる。
リンクは「行き先」、ボタンを押すのは「ワープ」。80〜90年代の家庭用ゲーム機とチップチューンの手触りを、今のブラウザで再現する。

キーワード：ピクセルアート / CRT / 8bit / ステージセレクト / 夜空

## 色

紺色の夜空に、ピンクとシアンのネオンを差す。使う色はこれだけにしぼる。

| 変数 | 色 | 役割 |
| --- | --- | --- |
| `--bg` | `#0f0b1e` | 背景（夜空） |
| `--bg-grid` | `#1a1433` | 背景の方眼線 |
| `--fg` | `#f4f4f4` | 文字、ボタンの枠、白い星 |
| `--accent` | `#ff4fa3` | ピンク。タイトルの影、▶ カーソル、ピンクの星 |
| `--accent-2` | `#3ee8ff` | シアン。サブタイトル、アイコン、シアンの星 |
| `--btn` | `#2a2150` | ボタンの地 |
| `--btn-hover` | `#3d2f78` | ボタンにカーソルが乗ったとき |
| `--muted` | `#8a80b8` | フッターや補足の控えめな文字 |
| `--gold` | `#ffd84a` | 実績・トロフィー・INSERT COIN だけに使うごほうびの色 |
| `--shadow` | `#000` | ボタン・タイトルの落ち影 |

## 文字

- **Press Start 2P**：英字のタイトル・ボタン・UI。基本は全部これ
- **DotGothic16**：日本語を入れるとき用
- 英字の表記は**大文字**（`YOUTUBE`、`PRESS START`）
- 文字のアンチエイリアスは切ってドット感を残す

## ドットのルール

- **1ドット = 4px**（`--px`）。枠線や影のずれはこの単位でそろえる
- **ぼかしなし**：影はすべてぼかし 0 のベタ影。角丸・グラデーションは使わない（背景の方眼と走査線だけは例外）
- **枠はドットで描く**：ボタンの枠は `box-shadow` を上下左右に置き、角が1ドット欠けた昔のゲームの窓にする
- **アイコンは 12×12 マス**、1色。ボタン上では 24px（1マス = 2px）で表示
- **星は 2px 単位**に位置をそろえて動かす

## 動き

- **なめらかに動かさない**：アニメーションは `steps()` でコマ送りにする。`ease` などのなめらかな変化は使わない
- **点滅は `steps(1)`**：カーソル `_`、▶、PRESS START はパッと消えてパッと出る
- **起動の流れ**：
  1. PRESS START が点滅
  2. 押すと3回チカチカして消える
  3. タイトルが上から落ちてくる
  4. サブタイトルとフッターが出る
  5. リンクボタンが上から順に1つずつ出てくる
- **押したとき**：ボタンは右下に1ドット沈み、落ち影が消える
- **動きを減らす設定**のときは、星を止め、アニメーションはすぐ終わらせる

## 音

すべて Web Audio API で鳴らす。音源ファイルは使わない。

- **音色**：メロディと効果音は矩形波（square）、ベースは三角波（triangle）、ハイハットはノイズ。昔のゲーム機の音源と同じ組み合わせ
- **効果音**：
  - カーソルが乗る → 短い「ピッ」（880Hz）
  - クリック → 上にすべる「ピュイン」（440 → 1760Hz）
  - スタート → 「ド・ミ・ソ・ド〜」のジングル
  - ピクセをつつく → コイン（シ → ミ）
  - UFO を撃つ → ノイズの爆発音と、下がっていく低音
  - ワープゾーンが開く → 駆け上がるアルペジオ
  - 実績解除 → 「ソ・ソ・ソ・ド〜」のファンファーレ
  - 流れ星 → 上から下へキラキラ下がる音
  - ミニゲーム → 自機ショットは下がる「ピュン」、敵はノイズ、ゲームオーバーは下がっていくメロディ
- **BGM**：140BPM、Am → F → C → G の4小節ループ。少し切なくて前向きな、ステージセレクトの曲
- **音量は控えめ**に。BGM はいつでも OFF にできる
- 音は**ユーザーが PRESS START を押してから**鳴らす（いきなり鳴らさない）

## ナビゲーター「ピクセ」

- 白くて丸い、アンテナ付きの小さな宇宙人。ほっぺはピンク
- 16×16 マス、1マス = 4px で表示。色は `PALETTE`（輪郭 黒 / 白 / ピンク / シアン）の中だけで描く
- しゃべり方は**ひらがな多め・わかち書き**の、昔の RPG のメッセージ風（「ようこそ！ ぼくは ピクセ。」）
- 文字は1文字ずつ出し、2文字ごとに小さな「ピッ」を鳴らす
- 隠し要素のヒントは、ピクセのセリフにさりげなく混ぜる

## 遊び要素

ゲームっぽさは「触ると何かが起きる」で出す。ただしリンク集としての使いやすさは邪魔しない。

- **スコア**：触ったものにはポイントを付け、`+100` のような数字をカクカク浮かせる
- **ワープ**：リンクを押したら星が光の筋になり、画面が4pxゆれる。リンクは新しいタブで開くので、演出を待たせない
- **UFO**：ときどき飛んでくる、撃てるボーナスキャラ。動きは `steps()` でコマ送り
- **隠し要素**：コナミコマンドと、タッチ端末向けの別ルート（ピクセ10連打）を必ず両方用意する
- **ポーズ**：タブを離れたら BGM を止める

### ゲームボーイモード

隠しコマンド `gameboy` のときだけ、上の変数を初代ゲームボーイの4色（`#0f380f` `#306230` `#8bac0f` `#9bbc0f`）に差しかえる。
スプライトは CSS 変数で塗っているので、ピクセや UFO もいっしょに緑になる。

## ゲーム要素

「ちょっとやりすぎ」くらいまで遊んでいい。ただし**リンク集として使う人のじゃまはしない**。

- **入り口はさりげなく**：ミニゲームはフッターの INSERT COIN、実績は左上の小さなトロフィー。リンクより目立たせない
- **見つける楽しさ**：隠しコマンドや実績はヒントだけ出し、答えは README のネタバレにまとめる
- **どの端末でも全部できる**：キーボードだけの要素には、タッチ用の別ルートを用意する（コナミコマンド ↔ ピクセ10連打、単語入力 ↔ CHEAT CODE 欄、ミニゲームはドラッグ操作）
- **ミニゲームは 160×144**：ゲームボーイと同じ解像度で描いて、整数倍に拡大する
- **実績は 20 個**：取ったらファンファーレと ACHIEVEMENT UNLOCKED。ぜんぶ取るとピクセがお礼を言う
- **点滅は控えめに**：パーティーモードの背景は暗い色どうしを 0.5 秒ごとに切りかえる。明るい色での速い点滅（1秒に3回以上）はしない

## やらないこと

- 写真やなめらかなイラストを入れる
- 角丸、ぼかし影、グラデーションのボタン
- ふわっとしたフェードやイージング
- 決めた色以外の色を足す（足すときはこの表に追加してから）
