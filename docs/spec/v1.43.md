## ひみつの こうじょう

- ワープゾーンを おすと、いつもの ワープ ダイブ（ピクセが ワープあなに とびこむ）の 0.75 びょう あとに つく。ダイブ しない とき（うごきを へらす・シンプルモード など）は すぐ
- こうじょうに いる あいだは ピクセは もどって こない（ダイブの「2.2 びょうで もどる」を とめる）。とじると「むこうに いって きた」ことに して、ひみつの かぎの おみやげと「ただいま！ ひみつの こうじょうを のぞいてきた。コードが いっぱい！」
- まどの なか：あおい せっけいずの かみに、しろい せんの ピクセ（「PIXE / DESIGN No.1」）、「ピクセ「ようこそ、ワーピクスの ひみつの こうじょうへ！」」「warpix-link は、ここに ある せっけいず（プログラム）で うごいてるんだ。だれでも みられる ように、おいて あるよ。」
- ここでしか みられない もの：いまの 版（`sw.js` の VERSION から。オフラインでも キャッシュから）、きみと であって ◯にち（あえた ひ）、きみが ワープした かいすう（`warpix-links` の 合計）
- 「せっけいずは えいごと プログラムの ページ（GitHub）です。むずかしいけど、のぞいても だいじょうぶ。」
- ボタン：「せっけいずを みる」（GitHub を あたらしい タブで）／「もどる」。✕・Esc・まどの そとでも とじる

## テスト（`tests/kojo.test.mjs`）

1. ワープゾーンを おすと こうじょう（そとへ とばない）。版・ワープの かいすう・せっけいずの ピクセ・GitHub の リンク（あたらしい タブ）
2. こうじょうに いる あいだは もどって こない。「もどる」で とじると「ただいま！… ひみつの こうじょう…」
3. うごきを へらす ときは すぐ ひらく。Esc で とじる
