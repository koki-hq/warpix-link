## ピクセの ゆめ

- **いつ**：ほうっておいて ピクセが ねむったとき（40 びょう）から、おきるまで。デモプレイの あと ページごと ねむるときは、え を のこして とまる。シンプルモードでは 出さない
- **ふきだし**：ピクセの みぎうえ。24×14 の ドット絵を 3 ばいで、2 コマで うごく（0.65 びょうごと）。4.2 びょうごとに つぎの ゆめへ。読み上げには 出さない（かざり）
- **ゆめの えらびかた**：さいきん 2 しゅうかんの 日記を あたらしい じゅんに見て、さいだい 3 つ ＋ いちばん よく行く リンクの ゆめ。2 つに たりなければ「ひつじを かぞえる」「おつきさまに いく」

| ゆめ | 日記の できごと |
| --- | --- |
| ボスと たたかう | `boss`・`raid` |
| UFOに のる | `ufo` |
| きょくを つくる | `song`・`shelf`・`gift` |
| ぼうけんする | `adventure`・`ghost` |
| ランキング 1いに なる | `rank` |
| ◯◯へ ワープする | よく行く リンク（`warpix-links`） |
| ひつじを かぞえる／おつきさまに いく | なにも ない ひ |

- **おきたとき**：「はっ！ ねてないよ！」の つぎに「……◯◯ ゆめ なんて みてないってば。」（おきた ときに 見ていた ゆめ）。イベント `dream { name }`、実績「ゆめみる ピクセ」、日記「◯◯ ゆめを みたって。」
- **うごきを へらす**：1 まいの え だけ（うごかない・かわらない）
