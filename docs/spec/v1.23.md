## かくれピクセ

- **なに**：ピクセの あたまだけの ちいさな え（8×6 マスを 3 ばい）。ばしょの ふちから のぞき、6 びょうに 1 かい、どれか 1 ぴきが 0.8 びょう ひっこむ（ずっと うごく アニメに すると 待機中の CPU が 15% → 18% に ふえたので、たまに クラスを つける かたちに した）
- **ばしょ**：13 か所（タイトル・サブタイトル・つき・ふきだし・リンク 6 つ・INSERT COIN・スコア・フッター）から、**その日の 日付で 3 か所**（おなじ日は いつも おなじ。日が かわると べつ）。うえ・した（さかさま）・ひだり／みぎ（よこむき）から のぞく
- **おきかた**：リンクの なかには いれず、ページの うえの べつの そう（`.hide-layer`）に おく。リンクの まんなかは ふさがない。PRESS START から 1.8 びょう（リンクが ならんでから）。がめんの おおきさや ふきだしの おおきさが かわったら おきなおす
- **みつける**（クリック・タップ・Tab で えらんで Enter）：50 てん、コインの おと、「みつかっちゃった！（1/3）」。3 びき ぜんぶで「ぜんぶ みつかっちゃった！ かくれんぼ、きみの かち！」、実績「かくれんぼ めいじん」、日記「かくれんぼで ちびピクセを 3びき ぜんぶ みつけた。」。みつけた こは その日 もう でない
- **でない とき**：シンプルモード、ミニゲームと ぼうけんの あいだ、いんさつ。うごきを へらす ときは ひっこまない
- **読み上げ**：「かくれている ちびピクセ」
- **ほぞん**：`warpix-hide`（`{ date, found: [ばしょ], wins }`）。`?date=` で のぞいているときは ほぞんしない
