## ひっこしで わかった こと（iPhone）

- iPhone（iPad）では、**ホームがめんに ついかした アプリごとに きろくの いれものが べつ**。Safari とも、ほかの ホームがめんアプリとも わかれている
- ふるい アイコンの アプリで「きろくごと ひっこす」→ いきさきが べつの じゅうしょ なので、アプリの なかに ブラウザの タブが ひらき、きろくは **その タブ**に はこばれる。そこから「ホームがめんに ついか」した あたらしい アプリは まっさら
- 2026-10-18 は、ユーザーが タブで じゅもんを コピー → あたらしい アプリで はって ひっこした。ふるい じゅうしょに きろくが あるのは ほぼ ユーザー だけ なので、コードは なおさない
- つぎに おなじ ような ひっこし（calendar.warpix.app など）を する ときは、iPhone の ホームがめんアプリ（`pocket.standalone()`）では べつの じゅうしょへ とばさず「じゅもんを コピー → あたらしい アプリで はってね」と あんない する
