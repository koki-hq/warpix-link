## なぜ

v1.6 から 20 回 ちかく 遊びを 足して、ピクセの もちものが 2 つの まどに わかれていた（にっき・ずかん・スタンプは ノート、じっせき・ぼうし・CHEAT CODE は じっせきの まど）。
踏み台リンク集なので、リンクの まわりは すっきり させたい。ピクセの ものは ぜんぶ おへやに しまう。

## ROOM ボタン

- 左から：おうちの アイコン（12×12、えんとつ つき）・`ROOM`・きんいろの トロフィーと じっせきの かず（`1/60`）・まだ よんでいない にっきが あると `NEW`
- 読み上げの 名前：「ピクセの おへや じっせき 1/60」（`ROOM` の 文字は 読まない）
- じっせきを とると ROOM ボタンが ひかる（`.ping`。うごきを へらす ときは ひからない）
- おすと いつも「にっき」の ページで ひらく（にっきを よんだ 実績も ここで つく）

## おへやの ページ（タブ 5 まい）

| タブ | なかみ | いろ |
| --- | --- | --- |
| にっき | ピクセの にっき（まえと おなじ） | クリーム |
| ずかん | ピクセの ずかん | クリーム |
| スタンプ | スタンプカード | クリーム |
| じっせき | ACHIEVEMENTS 一覧・WORLD RECORD・CHEAT CODE | こい いろ（`.room-dark`） |
| ぼうし | WARDROBE と「＋ ぼうしを つくる」 | こい いろ |

- タブは スマホ（390px）でも 1 だんに おさまる（はばを わけあう）
- 「ポストカード」「おみやげ」は ピンクの みだしの なか、✕ の となりに うつした
- ←→・Home・End で タブを えらぶ（まえと おなじ。5 まいに なった）
- WORLD RECORD は「じっせき」の ページを ひらいた ときに よみこむ（まえは じっせきの まどを ひらいた とき）
- WARDROBE は「ぼうし」の ページを ひらいた ときに かきなおす
- CHEAT CODE で コマンドが きまると、おへやを とじる
- アトリエを ひらくと おへやを とじ、アトリエを とじると ROOM ボタンに フォーカスが もどる

## コントローラー

- START：おへやの「じっせき」を ひらく・とじる。B：とじる
- 十字キーは、おへやの なかの **みえている** ボタンと いれる ところだけを めぐる

## ピクセの ことば

- ガイド：「ひだりうえの ROOM が ぼくの おへや。\nにっきや ずかんが あるよ。のぞいてみて。」「おへやの「ぼうし」で、\nぼくの ぼうしを かえられるよ。」「おへやの「ポストカード」で、\nぼくの えはがきが つくれるよ。」
- おるすばん：「じゃあ おへやに かざっておくね。\n（ROOM の「おみやげ」から みられるよ）」
- 実績の ヒント：ポストカード「ピクセの おへやの うえの ほうに……」、ぼうし デザイナー「おへやの「ぼうし」の となりで……」

## ほかの ファイルから

- `room.open(tab)`（`zukan.js`）：おへやを ひらいて ページを えらぶ。`tab` は `"diary"`・`"zukan"`・`"stamp"`・`"trophy"`・`"hat"`。ひらいている ときは ページだけ かえる
- チートの `diary`・`zukan` も `room.open` を つかう
- ページを かえると `notebook-tab` の できごと（`{ which }`）

## テスト（`tests/room.test.mjs`）

1. HUD の ボタンは ROOM だけ。まえの ボタンと まどが ない。ひらくと にっき、タブ 5 まい、じっせきの 行の かず、ぼうしが ならぶ、ひらきなおすと にっきに もどる
2. じっせきを とると ROOM が ひかって かずが ふえる。`room.open("trophy")`、ひらいたまま `room.open("stamp")`
3. にせものの パッドで START → じっせき、十字キーは みえる ところだけ、B で とじる
4. スマホ 390px で タブが 1 だん、タブや ボタンが まどから はみでない

ほかに、じっせきの まどや DIARY を つかっていた テスト（arcade・atelier・dream・grow・guide・online・postcard・rusuban・stamp・world・zukan）と 健康診断を、おへやに あわせて なおした。
