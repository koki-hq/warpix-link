## ピクセの ポストカード

ノート（DIARY）の上の「ポストカード」（またはコマンド `postcard`）。押すとノートを閉じて、できたはがきを見せる。

- **画像**：1200×630 の PNG。ブラウザの中（canvas）だけで作り、どこにも送らない
- **中身**
  - 夜空の方眼と星（毎回同じ並び。文字と吹き出しのまわりには置かない）とドットの枠
  - 大きなピクセ（いまの成長の姿と帽子。1 マス 18px）
  - 吹き出し：日記のいちばん新しい 1 行（「ポストカードを つくってもらった。」の行はのぞく。3 行まで）
  - WARPIX-LINK、いまの姿の名前、あえた ひ、HI-SCORE、ずかんと実績の数
  - 日付と、サイトのアドレス
- **ボタン**
  - **ほぞん**：`warpix-pixe-YYYY-MM-DD.png` として保存
  - **シェア**：画像ファイルを共有できる端末（スマホなど）でだけ出る
  - **とじる**（Esc でも）
- 画像の説明（alt）に、いまの姿の名前を入れる
- 作ると、実績「ポストカード」と、日記に「ポストカードを つくってもらった。」（1 日 1 行）
- 文字は、ドットのフォント（Press Start 2P・DotGothic16）を読みこんでから描く
