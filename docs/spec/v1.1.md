## 構成

## 起動の流れ

| 時間（クリック後） | できごと |
| --- | --- |
| 0 秒 | 起動ジングル。BGM 予約（0.8 秒後に開始） |
| 0〜0.45 秒 | PRESS START 画面が3回点滅して消える |
| 0.45 秒 | タイトルが落ちてくる |
| +0.5 秒 | サブタイトル・HUD・ピクセ・フッター・BGM ボタンが出る |
| +0.6 秒〜 | リンクボタンが 0.12 秒おきに1つずつ出る |
| +1.6 秒 | ピクセのあいさつ開始 |
| +15 秒 | 最初の UFO |

## スコア

| 行動 | 点 |
| --- | --- |
| リンクを押す | 100 |
| ピクセをつつく | 10 |
| UFO を撃ち落とす | 1,000 |
| ワープゾーンが開く | 5,000 |

- 左上の HUD に SCORE と HI を 6 桁で表示（最大 999999）
- 点が入ると、その場所に `+100` などがカクカク浮かぶ（0.8 秒）
- ハイスコアはブラウザに保存。PRESS START 画面にも HI-SCORE を出す

## ピクセ

- 16×16 マスの白い宇宙人（アンテナとピンクのほっぺ）。64px で表示し、1 秒ごとに 1 ドット上下する
- **まばたき**：3.2 秒ごとに 0.15 秒
- **あいさつ**（3行。ウィンドウをクリックで次へ）
  1. ようこそ！ ぼくは ピクセ。ここは ワーピクスの ほしぞら。
  2. したの ボタンを えらぶと その せかいへ ワープできるよ。
  3. ……そういえば ときどき そらを なにかが とんでるんだ。
- **文字送り**：45ms に1文字。2文字ごとに 1200Hz の小さな音。表示中にクリックすると全文を一気に出す。続きがあるときは ▼ が点滅
- **つつく**：ジャンプ＋コイン音（シ→ミ）＋10点。1.5 秒以内に続けてつつくと連続回数が増える
  - 1〜4回目：8 種類のひとことからランダム（直前と同じものは出さない）
  - 5回目：「……なんだか からだが むずむず してきた。」
  - 10回目：ワープゾーンが開く

## ワープ演出

- リンクを押すと、星が 1 秒かけて最大 25 倍まで加速して元に戻る（sin カーブ）
- 加速中の星は縦に伸びて光の筋になる（最大 64px）
- 同時に画面が 4px ずつ 0.3 秒ゆれる
- リンクは新しいタブで開くので、演出の終わりを待たない

## UFO

- 最初は 15 秒後、以降 20〜40 秒ごとに画面を横切る（左右どちらからかはランダム、高さは上から 40〜200px）
- 9 秒で横切る（90 コマのコマ送り）
- クリックするとその場で爆発（0.4 秒）、爆発音、1,000 点、ピクセが「ナイスショット！」
- タブが裏にあるときはその回をスキップ

## ワープゾーン

- **開き方**：コナミコマンド（↑↑↓↓←→←→BA）、またはピクセを 10 回連続でつつく
- **開くと**：パワーアップ音（ドからミまで 8 音のアルペジオ）、ワープ演出、タイトルの影がピンク → シアン → 紫とチカチカ、ピンク枠の WARP ZONE ボタン（鍵アイコン、リンク先は GitHub リポジトリ）が出る、5,000 点
- ピクセが「ひみつの ワープゾーンが ひらいた！」「いちばん したの ボタンを みてごらん。」

## ポーズ

- タブが裏に回ると音全体を一時停止し、タブ名を「PAUSE ⏸ warpix-link」にする。戻ると再開

## ブラウザに保存するもの

| キー | 中身 |
| --- | --- |
| `warpix-bgm` | BGM の ON / OFF |
| `warpix-hi` | ハイスコア |

## 動きを減らす設定のとき

- 星は止まった状態で表示。ワープしても加速しない
- 登場アニメーションはすぐ終わる。点滅・ゆれ・ピクセの上下はなし
- UFO は来ない
