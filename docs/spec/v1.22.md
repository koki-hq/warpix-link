## ピクセの こえ

- **オン・オフ**：せっていの「おと」の「ピクセの こえ」。**はじめは オフ**。オンに すると「こんにちは！ ぼくの こえ、きこえる？」と しゃべり、実績「ピクセの こえ」。`warpix-settings` の `voice`（`"on"`/`"off"`）に ほぞん
- **しゃべる もの**：ピクセの ふきだしの セリフ ぜんぶ（あいさつ・おしゃべり・しつもん）。つぎの セリフが はじまると、まえの セリフは とめる
- **こえ**：にほんご（`ja-JP`）、たかさ 1.8、はやさ 1.1、おおきさは こうかおんの おおきさ。にほんごの こえの うち、その きかいの なかの こえ（`localService`）を さきに えらぶ
- **よみかた**：かいぎょう・「……」は「、」に。♪★☆♥〜 は よまない。「、」が つづいたら 1 つに、「。！？」の あとの「、」は とる
- **しゃべっている あいだ**は、もじおくりの ピコピコ音を ならさない
- **とめる**：タブを うらに したとき。シンプルモードでは しゃべらない
- **よみあげが ない ブラウザ**：スイッチを つかえなくして「※ この ブラウザでは こえが でません。」
- **プライバシー**：きかいの なかの こえが ない ときは、ブラウザの 会社の サーバーで よみあげる こえに なり、セリフの もじが おくられる ことが ある（「このページについて」に かいた）
