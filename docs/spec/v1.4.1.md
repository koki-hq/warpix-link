## 共有カード

サイトの URL（`https://koki-hq.github.io/warpix-link/`）を X・Discord・LINE・Slack などに貼ると、次のカードが出ます。

| 項目 | 中身 |
| --- | --- |
| 画像 | `og.png`（1200×630）。左に大きなピクセ、右に WARPIX-LINK、PRESS A LINK TO WARP_、「ピクセが まってる、ドットの リンク集」、▶ PRESS START。右上に UFO、右下にみかづき |
| タイトル | WARPIX-LINK |
| 説明 | ピクセが まってる、ドットの リンク集。リンクを えらぶと その せかいへ ワープ。 |
| X のカードの形 | 大きい画像つき（`summary_large_image`） |

- 検索エンジン向けの説明文（`meta description`）も足した
- カードはページのリンクボタンの行き先とは関係なく、いつも同じものが出る
- X や Discord は一度読んだカードをしばらく覚えているので、カードを変えても、すぐには反映されないことがある

## カード画像を作り直す

1. `tools/og-card.html` の文字や絵を変える（ブラウザで開くと、そのまま見た目を確かめられる）
2. `node tools/shoot-og.mjs "<Chrome の場所>"` で 1200×630 に撮影して、`og.png` を上書きする
