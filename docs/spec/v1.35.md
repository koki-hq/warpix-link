## すうじキー

- 1〜6 を おすと、その ばんごうの リンクに フォーカスして おす（ふつうに おしたのと おなじ。あたらしい タブで ひらいて、ピクセも とびこみ、かいすうも かぞえる）。いれかえた カセットでも ばんごうどおり
- はんのう しない とき：Ctrl・⌘・Alt と いっしょ、おしっぱなし、もじを うつ ところ（input・textarea・select）、まど（`dialog`）や かさねた がめん（おみくじ・ポストカード・スタッフロール・ミニゲーム など `role="dialog"`）が ひらいている、PRESS START まえ、ミニゲームや ぼうけんの とちゅう
- シンプルモードでも つかえる（スタートが ないので すぐ）
- 実績「すうじで ワープ」：ヒント「キーボードの すうじを おすと……」

## ばんごう

- パソコン（`@media (hover: hover) and (pointer: fine)`）だけ、リンクの みぎはしに ちいさく「1」〜「6」（9px、シアンの わく）。スマホでは ださない
- よく いく せかいの ハートが ある リンクは、ばんごうを ハートの ひだりに（`:has(.fav-mark)`）
- よみあげでは よまない（`aria-hidden`）

## テストの ながしかた（`tests/run.mjs`）

- まえは ファイルの 大きさで さいしょに 4 つに わけていた ので、ながい テストが かたよると その ワーカーだけ さいごまで のこっていた
- いまは ながい ものから じゅんに ならべ、**あいた ワーカーが つぎの ファイルを とりにいく**。かかった じかんは `tests/.output/timings.json` に おぼえる（ぜんぶ ながした ときだけ）。しらない ファイルは 大きさで みつもる
- ふだんは **4 つ同時**のまま。はかった：4 つ（まえの やりかた）507〜645 びょう、6 つ 378 びょう、8 つ 352 びょう。いちばん ながい ぼうけん（やく 2.5 ぷん）が さいごまで のこるので 8 つでも あまり かわらず、どうじに うごくほど じかんに びんかんな テストが ゆれやすい。さらに 6 つで ながした あと、パソコンの メモリが たりなく なって ながすのを とめられた（テストの Chrome が 113 こ のこっていた）ので、4 つに もどした。はやく したい ときは `--jobs 6`

## テスト（`tests/keywarp.test.mjs`）

1. いれかえた カセットで 4 を おすと STUDYPLUS。実績、おきにいりの かいすう。7 や 0 では なにも ひらかない
2. スタートまえ・カセットの まど・CHEAT CODE に うっている ときは ひらかない。ふつうの ときは ひらく
3. シンプルモードでも ひらく。ばんごうは 123456、なまえに まざらない。スマホで かくす CSS の きまり が ある
