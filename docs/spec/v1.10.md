## せってい

フッターの「せってい」（またはコマンド `settings`）。シンプルモードでも出る。設定はこのブラウザに保存する（`warpix-settings`）。

| 項目 | 中身 | 反映 |
| --- | --- | --- |
| BGM の おおきさ | 0〜100（10 きざみ）。BGM ON/OFF とは別 | すぐ |
| こうかおんの おおきさ | 0〜100（10 きざみ）。つまみをはなすと、その大きさで 1 回コイン音 | すぐ |
| うごきを へらす | ほしや UFO を止め、点滅もしない。OS で「動きを減らす」にしているときは、いつもオン（変えられない） | ページを読みなおす |
| よみやすい もじ | ドットの文字（Press Start 2P・DotGothic16）を、端末のふつうの文字に | ページを読みなおす |
| キーそうさ | Tab、Enter・スペース、Esc、ミニゲームと冒険のキー、作曲のキー、コントローラー。ひみつのコマンドは書かない | — |

### うごきを へらす のしくみ

- `<head>` の中で、描く前に `html.reduce-motion` をつける
- JavaScript の `reduceMotion` が真になるので、OS の設定と同じように、星は止まり、UFO・流れ星・ピクセの雨・キラキラ・デモプレイは出ない
- CSS は `html.reduce-motion` のとき、すべてのアニメーションを 1ms・1 回で終わらせる（点滅や上下ゆれは止まり、登場の演出はすぐ最後の形になる）

### よみやすい もじ のしくみ

- `<head>` の中で `html.plain-font` をつけ、すべての文字を `system-ui`（端末のふつうの文字）にする。字間も ふつうに戻す
- ミニゲームの画面の中の文字（canvas）は、ドットの文字のまま
