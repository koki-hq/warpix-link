### セリフ（変更）
- ワープで ほかの アプリに いって いる あいだは「なにも して いない じかん」に いれない（もどった とき かぞえなおす）。「ちょっと ねむく なってきた」も npc.free() の あと（もどった とたんに「ただいま」と ぶつかって いた）
- じぶんの リンクの ワープご「ただいま！ ぼくも いっしょに みてきたよ。」→「ただいま！ ワープ、たのしかったね。」（みられて いた かんじが する、本人。ほかの リンクの セリフは さわらない）
- ひみつの こうじょうから もどった とき「…コードが いっぱい！」→「ただいま！ ひみつの こうじょう、だれにも いっちゃ だめだよ。」（v1.58 で ソースコードは みせなく なった）

- あさの あいさつの「かるい わだい」（きせつ・ヒント など）を いわない きじゅんを、だいじな はなしが 2 ぎょう いじょう → **3 ぎょう いじょう** に（プレゼントの 2 ぎょう だけで ヒントが きえて いた）

### おと（変更）
- iPhone で アプリから もどって 音が ねて いる とき：BGM ボタンは「BGM ♪z」、ピクセの あたまに「♪z」が ゆれる。どこかを タップすると 音が もどって ピクセが はねる。セリフは ださない。**iPhone は タップ（ゆびを はなす）が ない と 音を もどせない**（スクロールでも だめ。iPhone の きまり）。Android や パソコンは もどった とき じどうで もどる（まえから）

### ピクセの へや（変更）
- まど（dialog）を ひらいて いる あいだは うしろの がめんを スクロール させない（`html:has(dialog[open])`、まどの なかは overscroll-behavior: contain）
