## スタンプカード

- **場所**：ノート（DIARY）の 3 つめの タブ「スタンプ」
- **カレンダー**：ひと月ぶん、日曜はじまり。さいしょは きょうの つき。◀ ▶ で、はじめて あった つき 〜 きょうの つき のあいだを うごく（はしでは おせない。フォーカスは のこる）
- **スタンプ**：あえた ひ（`grow` の `days`）に 1 つ。その日の 日記の できごとで しゅるいが かわる。上のほうが つよい

| スタンプ | できごと（日記の しゅるい） |
| --- | --- |
| おみやげ（プレゼント） | `rusuban` |
| ボス（ほし） | `boss` |
| ランキング（おうかん） | `rank` |
| ぼうけん（はた） | `adventure`・`ghost` |
| おんがく（おんぷ） | `song`・`shelf`・`gift` |
| UFO | `ufo`・`raid` |
| ふつう（ピクセの かお） | それいがい |

- **見た目**：ノートの かみに こい インク 1 色。日付で きまる かたむき（−12〜12 ど）。きょうは ピンクの わく
- **読み上げ**：カレンダーは 表。見出しに「◯ねん ◯がつの スタンプ（あえた ひ ◯にち）」、スタンプの ある日は「ボスを たおした ひ」など、きょうは `aria-current="date"`
- **した**：この つきの 日数・いまの れんぞく（きょう まだなら きのうから）・さいちょうの れんぞく。スタンプの しゅるいの 一覧
- **実績**：いまの れんぞくが 7 日いじょうで「まいにち スタンプ」
- **保存**：あたらしい 記録は ない（`grow` の 日と 日記から つくる）
