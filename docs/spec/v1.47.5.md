## v1.47.4 からの変更

- **原因**：ちびピクセの 層は たかさ 0。v1.47.4 で「よこだけ きる」（`overflow-x: clip; overflow-y: visible`）に したが、iPhone の ブラウザは たても きって しまい、ぜんぶ 見えなく なった。「ひょこっ」の うごきの あいだだけ べつの 描きかたに なって 見えて いた。パソコンの Chrome では ねらいどおりに うごくので、テストでは 気づけなかった
- **変更（style.css）**：`.hide-layer` は `overflow: hidden`（どの ブラウザでも おなじ）・`pointer-events: none`。ちびピクセ だけ `pointer-events: auto`
- **変更（hide.js）**：`reposition()` で 層の たかさを ページ ぜんたいに（じぶんを 0 に して はかった `scrollHeight` と、いちばん したの ちびピクセの した はし ＋ 8px の 大きい ほう）
- **テスト**：`hide` の「スマホの はばで…」に、どの ちびピクセも 層の なかに おさまって いる・層の たての きりかたが `hidden`・層が かぶっても リンクが おせる、を 足した（v1.47.4 の きりかたでは こける）
- **変更**：サービスワーカーのキャッシュ名を `warpix-v1.47.5` に
- 実績 70 個・テスト 178 件（かわらず）
