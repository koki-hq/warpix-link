## 入れる 文字（`tools/fonts.mjs`）

- ASCII（0x20〜0x7E）ぜんぶ ＋ ひらがな（ぁ〜ゖ）・カタカナ（ァ〜ー）ぜんぶ ＋ `index.html` と ルートの `*.js` に でてくる 文字
- かなを ぜんぶ 入れるのは、製作所だより（ホームページの news.json）の 題を ピクセが よむ ため。そこに しか ない 漢字は ふつうの 字に なる
- Google Fonts の `css2?family=DotGothic16&text=…` で その 文字 だけの woff2 を もらって おく（Chrome の ふりを して woff2 を もらう）
- Press Start 2P は 予約された 名前（RFN）つき なので しぼった ものを 配れない（OFL FAQ 2.6）→ Google Fonts の まま（ラテン文字 だけ 12 KB）
- 文字を ふやしたら `node tools/fonts.mjs`。わすれると `tests/fonts.test.mjs` が たりない 文字を おしえる（`--check` でも）
