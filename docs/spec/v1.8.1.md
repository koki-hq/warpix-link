- **タグ**：`v1.8.1`（2026-10-16）
- **ひとこと**：冒険で、いちばん下からまた上へ登れるように直した
- **前のバージョン**：[v1.8](v1.8.md) ／ [バージョン一覧](README.md)

ここには v1.8 から変わったところだけを書きます。

## v1.8 からの変更

- **修正**：スマホの冒険で、いちばん下に落ちると INSERT COIN までは登れるが、そこから上（いちばん下のリンク）へ登れなかった
- **修正**：フッターの「おみくじ」に乗れなかった（足場の一覧に入っていなかった）
- **追加**：テスト 2 件（合計 57 件）
- **変更**：サービスワーカーのキャッシュ名を `warpix-v1.8.1` に

## 原因

ピクセのジャンプで上がれる高さは、初速 −10.5・重力 0.5 だと、10 + 9.5 + … + 0.5 ＝ **ちょうど 105px**。
INSERT COIN からいちばん下のリンクまでの高さの差は、もともと 105px ぎりぎりだった。v1.8 でフッターに少し背の高い「おみくじ」が並んだため、INSERT COIN が数 px 下にずれて 105〜106px になり、1px 届かなくなった。

## 直したこと

| | v1.8 | v1.8.1 |
| --- | --- | --- |
| ジャンプの初速 | −10.5（上がれる高さ 105px） | **−11（約 115px）** |
| 足場 | リンク、会話ウィンドウ、ピクセの箱、タイトル、サブタイトル、INSERT COIN | ＋ **おみくじ、このページについて** |
| 地面 | いちばん下の足場の 56px 下 | **44px 下**（地面に立ったピクセの頭の上に 12px あく） |

- スマホではフッターが 2 行に折り返すので、「このページについて」（下の段）→ INSERT COIN → いちばん下のリンク、のように階段にして登れる。地面から、おみくじ（上の段）にも真下からジャンプで届く
- 勢いよく着地すると、おみくじと「このページについて」も一瞬へこむ
- ゴーストの記録でも、おみくじ（`o`）と「このページについて」（`a`）を足場の名前として使う

## テスト

`tests/adventure.test.mjs` に追加：

- **どの画面サイズでも、すべての足場からジャンプで 1 つ上の足場に届く**：360・390・430・768・1280・1920 の幅で、地面といちばん上以外のすべての足場について、横 200px 以内・上に 110px 以内に別の足場があることを確かめる。今後フッターなどに部品が増えて段差が広がると、ここで気づける
- **スマホで、いちばん下からフッターの足場を階段にして、リンクまで登れる**：390×844 で地面まで落ちて、本物のキー操作で INSERT COIN → リンクへ登り、もう一度落ちて、おみくじにも乗る
