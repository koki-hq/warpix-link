# warpix-link 仕様メモ v1.50.3「BGM TAP を ほんとうに」

- **タグ**：`v1.50.3`（2026-10-20）
- **ひとこと**：v1.50.2 の「BGM TAP!」は、iPhone で タップしても なおらなかった（本人「Spotify で 音 止めて もどって きても BGM TAP の まま、ボタン おしても 何も 反応 ない。セリフか リンクを おさないと なおらない」）。iPhone は **ゆびを はなした とき（touchend・click）** しか 音を おこさせて くれないのに、v1.50.2 は ゆびが ふれた とき（pointerdown）に おこそうと して いた。セリフや リンクで なおったのは、そこが click で 効果音を ならして、ついでに 音を おこして いた から
- **前のバージョン**：[v1.50.2](v1.50.2.md) ／ [バージョン一覧](README.md)

## v1.50.2 からの変更

- **なおし（script.js）**：タップまち（「BGM TAP!」）の あいだは、どこで ゆびを はなしても（`touchend`・`click`、capture）音を おこす。「BGM TAP!」の ボタンも おせば 音が もどる（OFF には ならない）。pointerdown で おこすのは やめた
- **テスト**：`day-use` の BGM TAP の テストを iPhone と おなじ に した（音が おきるまで 4 びょう まで まつ。5 並列で 0.8 びょうでは まにあわなかった）。にせの AudioContext は `click`・`touchend` の なかで しか おきない。v1.50.2 の コードは この テストで こける（「BGM TAP!」の まま）ことを たしかめた
- **変更**：サービスワーカーのキャッシュ名を `warpix-v1.50.3` に
- 実績 70 個・テスト 192 件（かわらず）
