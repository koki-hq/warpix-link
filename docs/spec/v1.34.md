## しらべた こと

360×640・390×844・768×1024・1280×720・844×390・667×375 で、いつもの がめんと 11 の まど（にっき・ずかん・スタンプ・じっせき・ぼうし・カセット・このページについて・せってい・さっきょく・アトリエ・てがみ）を ひらいて

- ページや まどが よこに はみださないか、まどの なかみが まどから はみださないか
- うえの ボタン（ROOM・♪・SIMPLE・BGM）や リンクの いれかえが、ほかの ものに かくれず おせるか

## みつけた こと

- **スマホの よこむき（たかさ 600px みまん）で、カセット えらびの たなが ほとんど みえない**：v1.28 で「いまの 6 こ」を うえに はりつけた（`position: sticky`）ので、ひくい がめんでは それだけで まどが うまっていた
  → たかさ 600px いじょうの ときだけ はりつける。ひくい がめんでは いっしょに スクロール
- ROOM ボタンが ながく なって、ひだりうえの かたまり（HUD）の とうめいな はこが ♪ の うえまで かかっていた。ただし ♪ の ほうが うえに かさなっていて ちゃんと おせる（320px でも）。なおさず、テストで みはる
- ほかは もんだい なし（いちばん ながい なまえの YOUTUBE MUSIC・にほんごの スタディサプリ・ニコニコ動画を いれて しらべた）

## かえた こと

- `style.css`：`.cas-head` は ふだん `position: static`、`@media (min-height: 600px)` で `sticky`
- サービスワーカーのキャッシュ名を `warpix-v1.34.0` に
