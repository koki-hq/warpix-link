## 構成

ビルドなし。`index.html` が次のスクリプトを順に読み込みます（ES モジュールではなく普通の `<script>`。`file://` で開いても動かすため）。

| ファイル | 役割 |
| --- | --- |
| `config.js` | オンライン機能の設定（Supabase の公開用 URL とキー）。空ならオンライン機能は動かない |
| `script.js` | 土台。アイコン、サウンド、星、スコア、ピクセ（会話・選択肢・留守・帽子）、ワープゾーン、UFO、PRESS START、きょうの日付（`today()`） |
| `game.js` | ミニゲーム PIXE INVADERS（デモモードつき） |
| `extras.js` | 実績、隠しコマンド、マザーシップ、流れ星、居眠り→デモプレイ、行き先紹介、キラキラ、コンソール |
| `adventure.js` | PIXE ADVENTURE |
| `world.js` | きせかえ、ファビコン、月、タブ間のピクセ、ピクセが気づく、冒険のおさそい、スタッフロール、認定証 |
| `season.js` | 季節イベント |
| `device.js` | ホーム画面に追加（PWA）、オフラインのひとこと、ゲームのコントローラー |
| `weather.js` | 本物の天気 |
| `online.js` | ほかの訪問者と同じ空 |
| `grow.js` | ピクセの成長・気持ち・記念日・日記 |

ほかに、`sw.js`（オフライン用のサービスワーカー）、`manifest.webmanifest`（アプリの名前・アイコン）、`icons/`（アプリのアイコン）があります。

ファイルどうしはトップレベルの `const`（`sound`、`stars`、`score`、`npc`、`game`、`achievements`、`cheats`、`adventure` など）を共有しています。
`script.js` はできごとを**イベントバス**で知らせ、ほかのファイルは `on(名前, 関数)` で受け取ります。土台に手を入れずに遊び要素を足すための仕組みです。

## 起動の流れ

| 時間（クリック後） | できごと |
| --- | --- |
| 0 秒 | 起動ジングル。BGM 予約（0.8 秒後に開始） |
| 0〜0.45 秒 | PRESS START 画面が3回点滅して消える |
| 0.45 秒 | `boot`。タイトルが落ちてくる |
| +0.5 秒 | サブタイトル・HUD・ピクセ・フッターが出る |
| +0.6 秒〜 | リンクボタンが 0.12 秒おきに1つずつ出る |
| +1.6 秒 | ピクセのあいさつ開始（3行＋2回目以降の来訪なら1行。ウィンドウをクリックで次へ） |
| +15 秒 | 最初の UFO |
| +25 秒 | 最初の流れ星。ピクセの「そとに でてみたい」おさそい（あいさつを読み終えていれば） |
| +60 秒 | 天気を調べていいか聞く（まだ答えていなければ） |
| +90 秒 | ホーム画面に追加できる環境なら、おさそい |

**ホバーの扱い**：スタートをクリックした位置にボタンが出てくると、マウスを動かしていなくてもホバー扱いになります。そのため、行き先紹介はあいさつを言い終えるまで出さず、ホバー音はスタート後にマウスが実際に動くまで鳴らしません。

## スコア

| 行動 | 点 |
| --- | --- |
| リンクを押す | 100 |
| ピクセをつつく | 10 |
| ピクセの雨をつかまえる | 50 |
| マザーシップに当てる | 200（1発ごと） |
| 流れ星をつかまえる | 500 |
| UFO を撃ち落とす | 1,000 |
| ワープゾーンが開く | 5,000 |
| マザーシップを撃沈 | 10,000 |
| ミニゲーム | ゲームの点をそのまま加算 |
| 冒険のコイン | 100 |
| 冒険で UFO を踏む | 200 |
| 冒険をクリア | 3,000 ＋ 速さボーナス（60 秒からの残り秒数 × 50、60 秒をこえたら 0） |

- **コンボ**：前の得点から 1.5 秒以内に点が入るとコンボが続く。倍率は「1 + コンボ数 ÷ 5（切り捨て）」で、最大 x4。ミニゲームの点を加算するときも倍率がかかる
- **表示**：6 桁（最大 999999）。点が入ると `+100` や `+400 x4` がカクカク浮かぶ
- **ハイスコア**：ブラウザに保存。PRESS START 画面にも出る

## ピクセ

- **あいさつ**：時間帯で1行目が変わる（0〜5時「よふかし？」/ 5〜10時 おはよう / 10〜17時 こんにちは / 17〜24時 こんばんは）
- **文字送り**：45ms に1文字。2文字ごとに小さな音
- **まばたき**：3.2 秒ごとに 0.15 秒
- **つつく**：ジャンプ＋コイン音＋10点。1.5 秒以内に続けてつつくと連続回数が増える
  - 1〜4回目：ランダムなひとこと（直前と同じものは出さない）
  - 5回目：「むずむず してきた」
  - 10回目：ワープゾーンが開く
- **行き先紹介**：あいさつを言い終えたあと、リンクにカーソルを乗せる（またはフォーカスする）と紹介する。同じリンクで2回続けては言わない
- **居眠り**：40 秒間なにも操作がないと寝る（目を閉じて「Z z z」）。マウス・キー・タッチ・ホイールのどれかで起きる。ミニゲーム中・冒険中・留守中・タブが裏にあるときは寝ない
- **デモプレイ**：寝てからさらに 20 秒たつと、ミニゲームが自動で遊ばれはじめる（下の「デモプレイ」）
- **おさそい**：起動 25 秒後、あいさつを読み終えていて手が空いていれば「この まどの そとに でてみたいな」と選択肢つきで聞く
  - 「いいよ！」：PIXE ADVENTURE が始まる
  - 「だめ」：あきらめる（その来訪ではもう聞かない）
  - ほかのセリフに割りこまれたとき：30 秒後にもう一度聞く
- **2回目以降の来訪**：あいさつの最後に「また きてくれたんだ！ ◯かいめ だね。」（10 回目から「じょうれんさん」、100 回目から「すんでるでしょ」）
- **気づくこと**：あいさつを読み終えていて、ほかに何もしていないときだけ反応する

  | できごと | セリフ（要約） | 回数 |
  | --- | --- | --- |
  | 30 秒以上ほかのタブに行って戻る | おかえり！ ◯びょう／ふん／じかん どこ いってたの？ | 毎回 |
  | テキストをコピー | コピーした？ なにを もっていくの？ | 1 回 |
  | 窓の幅が 380px 未満 | せ、せまい……！ | 1 回 |
  | 窓の幅が 1600px より大きい | ひろーい！ | 1 回 |
  | CAPS LOCK のまま英字を打つ | CAPS LOCK が ついてるよ！ | 1 回 |
  | ピクセにカーソルを 3 秒乗せる | じっと みられると てれる | 1 回 |
  | ピクセを右クリック | みぎクリックは くすぐったいよ！（メニューはふつうに出る） | 毎回 |
  | カーソルが画面の上から出ていく | もう いっちゃうの？ | 1 回 |

- **帽子**：きせかえで選んだ帽子を、箱の中・冒険中・ファビコン・スタッフロール・認定証のどこでもかぶる

## ワープゾーン

- **開き方**：コナミコマンド（↑↑↓↓←→←→BA）、またはピクセを 10 回連続でつつく

## ミニゲーム PIXE INVADERS

- **入り口**：フッターの INSERT COIN、またはコマンド `invaders`
- **画面**：160×144 で描いて、画面に収まる最大の整数倍に拡大。60fps 固定で更新
- **操作**：← → / A D、またはドラッグ（タップした位置へ向かう）。ショットは自動（16 フレームごと、画面に最大 3 発）
- **自機**：ライフ 3。被弾後 90 フレーム無敵（点滅）
- **敵**：6 列 × 3 段。端に着くと 4px 下がって折り返す。残りが少ないほど、ウェーブが進むほど速い
  - 行進の間隔（フレーム）＝ max(3, 28 − (18 − 残り数) × 1.4 − ウェーブ × 2)
  - 1歩ごとに「0.25 + ウェーブ × 0.05」の確率で、どれか1体が弾を撃つ
- **点**：上の段から 30 / 20 / 10 点 × ウェーブ数。ウェーブクリアで 100 × ウェーブ数
- **終わり**：ライフが 0、または敵が自機の高さまで来たらゲームオーバー。タップか Space / Enter でリトライ
- **閉じる**：✕ ボタンか Esc。途中で閉じても、そこまでの点はページに入る
- タブが裏に回ると一時停止し、戻ると続きから

### デモプレイ（アトラクトモード）

- ピクセが寝てから 20 秒、だれも操作しないと、ミニゲームが自動で遊ばれる（ゲームセンターの筐体のように）
- 画面に DEMO PLAY / PRESS ANY KEY が点滅。効果音は鳴らさず、点はページに入らず、実績にも数えない
- 自機は、いちばん近い敵の下へ向かい、真上から来る弾をよける
- ゲームオーバーになると約 2.5 秒後に最初から
- マウス・キー・タッチ・ホイールのどれかで閉じて、ピクセも起きる
- 「動きを減らす」設定のときは始まらない

## PIXE ADVENTURE

ピクセが箱を飛び出し、**ページにある本物の要素を足場にして**跳びまわるアクションゲームです。

- **始めかた**：ピクセのおさそいに「いいよ！」、またはコマンド `adventure`
- **足場**：リンクボタン、会話ウィンドウ、ピクセの箱、タイトル、サブタイトル、INSERT COIN。どれも**すり抜け床**（下からは通り抜け、上からは乗れる）
- **地面**：いちばん下の足場の 56px 下（ページの底のほうが近ければ底）。冒険中はシアンの点線で見える。どこに落ちても、地面からジャンプでいちばん下の足場に戻れる
- **足場が動いたとき**：ピクセ・コイン・UFO・ゴールは「どの足場から何 px か」で位置を覚えていて、画面サイズが変わったときと 0.5 秒ごとに足場を測り直し、いっしょに動く（空中にいるピクセは、ページの中身の枠についていく）
- **ピクセ**：32×32px（16×16 を 2 倍）。箱は「るす」になる
- **操作**

  | 入力 | キーボード | タッチ（ボタンが出る） |
  | --- | --- | --- |
  | 移動 | ← → / A D | ◀ ▶ |
  | ジャンプ | Space / ↑ / W / Z | A |
  | 足場から下りる | ↓ / S | ▼ |
  | やめる | Esc | 上の ✕ もどる |

- **動きの数値**（1 フレーム = 1/60 秒）
  - 加速 0.45、最高速 3.2px、手を離すと毎フレーム 0.78 倍
  - 重力 0.5、ジャンプの初速 −10.5（約 110px 跳べる）、落下は最大 12px
  - ジャンプボタンを早く離すと低いジャンプ（上昇速度を −4 で打ち切る）
  - 先行入力と、足場から落ちた直後の猶予がそれぞれ 6 フレーム
  - ↓ で下りた足場には 12 フレームのあいだ乗らない
- **コイン**：8 枚。ピクセの箱以外の足場からランダムに選び、その 44px 上に置く。1 枚 100 点
- **UFO**：幅 120px より広いリンクボタン 2 つの上を、毎フレーム 0.7px で往復
  - 上から踏む（ピクセの足が UFO の上端から 14px 以内）と倒せて、200 点
  - 横から当たると、はじかれて 1 秒無敵（点滅）。点は減らない
- **ゴール**：コインを全部取ると、タイトルの上に星が出る。さわるとクリア
- **クリア**：タイム表示、自己ベストを保存、ボーナス点、星がワープ。その来訪でまだスタッフロールを見ていなければ 3.5 秒後に流れる
- **勢いよく着地**（落下速度 7 より上）したリンクボタンや INSERT COIN は、一瞬へこんで音が鳴る
- **カメラ**：ピクセが画面の上 100px より上、下 180px より下に行くとスクロールして追いかける
- タブが裏に回ると一時停止。リンクボタンは冒険中もふつうに押せる

## タブをこえるピクセ

同じページを2つ以上のタブで開くと、タブどうしが `BroadcastChannel("warpix-link")` で話します（同じブラウザ・同じサイトのタブだけ）。

- **気づく**：ほかのタブを見つけると「ほかの タブにも ぼくが いる きがする……」（実績「パラレルワールド」）
- **遊びに行く**：ピクセをダブルクリックすると、1.2 秒後にとなりのタブへワープ。自分の箱は「るす」に（実績「タブを こえて」）
- **お客さんが来たタブ**：箱のとなりに、帽子もそのままのピクセが来て「おじゃまします！」
  - そのタブが裏にあるときは、タブのアイコンが「!」に、タイトルが「❗ ピクセが きたよ」になり、見に来たときにあいさつする
  - 30 秒たつか、お客さんをクリックすると「またね！」と帰る
- **帰ってくる**：元のタブのピクセが「ただいま！」
- 遊びに行った先のタブが閉じられたら、あわてて帰ってくる。帰る先のタブが閉じられたら、お客さんは「ここに すんでも いい？」

| メッセージ | 意味 |
| --- | --- |

## 生きているファビコン

- タブのアイコンは 16×16 のピクセル（canvas で描いて PNG にしたもの）。今の配色と帽子で描く
- 3.2 秒ごとに 0.15 秒まばたき
- タブが裏にあるとき・ピクセが寝ているときは目を閉じる
- 留守のときは影だけ。お客さんが来たのに見ていないときは「!」

## スタッフロール

- 黒い画面を下から上へ流れる（1 秒に約 40px、4px ずつカクカク）。最後の THE END ? が画面のまんなかで止まり、2.5 秒後に閉じる
- 中身：STARRING PIXE、MUSIC WEB AUDIO API、BUILD TOOL NONE、SPECIAL THANKS YOU などと、**あなたの記録**（スコア、ハイスコア、実績数、つついた回数、来訪回数、冒険のベスト）
- 流れているあいだは BGM が 0.7 倍のテンポになる
- クリック・Esc・Enter・Space でとばせる。最後まで見ると実績「エンディング」

## 印刷すると認定証

- ページを印刷する（印刷プレビューも）と、ページの代わりに**ピクセ公認の認定証**が出る
- 中身：帽子をかぶったピクセ、スコア、ハイスコア、実績数、つついた回数、来訪回数、冒険のベストタイム、取った実績の名前、日付、ピクセのサインと「ピ」のはんこ
- 白い紙に黒（はんこだけ赤）で印刷される。印刷しようとした時点で実績「かみに のこす」

## 本物の天気

- **聞いてから**：起動 1 分後に「そっちの てんき、しらべても いい？」と聞く。「いいよ」のときだけ位置情報を使う（ブラウザの許可ダイアログも出る）
- **送るもの**：位置は 0.1 度（約 10km）に丸めてから、天気サービス [Open-Meteo](https://open-meteo.com/)（無料・登録不要）に送る。ほかには送らない
- **次から**：一度「いいよ」と答えたら、次からは聞かずに調べる。結果は 30 分間ブラウザに保存して使い回す
- **やめる・聞き直す**：コマンド `weather` でもう一度聞く。「やめとく」と答えると、その後は聞かない

| 天気（WMO の天気コード） | ページ |
| --- | --- |
| 晴れ（0） | 夜なら星がカラフルに増える |
| くもり（1〜3） | ドット絵の雲が 3 つゆっくり流れる |
| 霧（45, 48） | うすい霧がゆらぐ |
| 雨（51〜67, 80〜82） | 雨が降る。ピクセがかさをさす |
| 雪（71〜77, 85, 86） | 雪が降る |
| 雷（95〜99） | 強い雨。9〜15 秒ごとにドットの稲妻と低いゴロゴロ。**画面は光らせない**（点滅が苦手な人のため） |

天気がわかると、ピクセが気温つきでひとこと言います（「そっちは あめ なんだね。いま 17ど。」）。

## ホーム画面に追加（アプリ）とオフライン

- `manifest.webmanifest` で、名前「WARPIX」、ピクセのアイコン、全画面表示（standalone）、背景色 `#0f0b1e` のアプリになる
- **サービスワーカー**（`sw.js`）が、ページの全ファイルを保存する。2 回目からは保存したものをすぐ表示し、裏で新しいものに更新する。Google Fonts も一度取れば保存する。天気とオンライン機能はネットに直接取りに行く
- **オフライン**でも開けて遊べる（天気・オンライン以外）。ネットが切れると「でも だいじょうぶ、ぼくは ここに いるよ！」、戻ると「つながった！」
- **おさそい**：インストールできる環境（Chrome・Android など）なら、起動 90 秒後にピクセが聞く。iPhone では、コマンド `install` でやり方（共有ボタン →「ホーム画面に追加」）を教えてくれる
- ホーム画面から開くと、あいさつの最後に「ホームがめんから きてくれたんだ！」
- `file://` で開いたときは、サービスワーカーを登録しない
- **公開するたびに** `sw.js` の `VERSION` を上げる（上げないと、古いファイルが残り続ける）

## ゲームのコントローラー

標準配置のコントローラー（Switch Pro、PlayStation、Xbox など）をつなぐと、ピクセが「コントローラー みつけた！」。

| ボタン | ふつうの画面 | ミニゲーム・冒険 |
| --- | --- | --- |
| 十字キー・左スティック | リンクを選ぶ（上下・左右で前後に移動） | 移動（↓ で足場から下りる） |
| A | 選んだものを押す（リンクならワープ） | ショット・ジャンプ・リトライ |
| B | 実績画面を閉じる | やめる |
| START | 実績画面を開く／閉じる | ショット・ジャンプ |

- 十字キーと B・A はキー入力としても流れるので、**コナミコマンドもコントローラーで入力できる**
- ピクセの質問の選択肢、実績画面の中も十字キーで選べる
- コントローラーで押したリンクは、新しいタブで開けないとき（ポップアップが止められたとき）は、そのタブでワープする

## ほかの訪問者と同じ空（オンライン）

`config.js` に Supabase の公開用 URL とキーが入っているときだけ動きます。入っていなければ、この機能はなにもしません（読み込みもしない）。

- **しくみ**：Supabase Realtime の公開チャンネル `warpix-sky` を使う。ライブラリ（supabase-js 2.45.4）は起動後に CDN から読み込む
- **送るもの**：タブごとのランダムな番号と、かぶっている帽子の ID だけ。名前・位置・スコアなどは送らない
- **いま見ている人**：HUD に「ONLINE 3」のように出る
- **空に浮かぶピクセ**：ほかの人のピクセ（帽子つき、半透明）が最大 8 匹ふわふわ浮かぶ。広い画面では左右の余白、せまい画面ではタイトルの上の帯に浮かび、リンクボタンにはかぶらない。場所は番号から決まる
- **つつく**：だれかが自分のピクセをつつくと、ほかの人の画面でもその人のピクセが跳ねる
- **手を振る**：浮かんでいるピクセをクリックすると、その人に手を振る（10 点）。振られた側のピクセは跳ねて「だれかが てを ふって くれた！」
- **はじめて人がいたとき**：「いま ◯にんで おなじ そらを みてる！」
- **世界の記録**：ピクセがつつかれた回数・ワープした回数・おとされた UFO を、全員ぶん数える。3 秒ごとにまとめて送る（1 回 20 まで）。実績画面の WORLD RECORD に出る
- **データベース**：`counters` テーブル（読むのは誰でも可、書きこみは `bump` 関数だけ）。だれでも数字を増やせるので、いたずらで水増しされる可能性はある
- オフラインや Supabase が止まっているときは、何も言わずにオンライン機能なしで動く

## ピクセが育つ

ピクセは、あなたが**来てくれた日の数**（同じ日に何回来ても 1 日）で育ちます。記録はこのブラウザの中だけに保存し、どこにも送りません。

### 成長

| 会えた日数 | 姿 | 手に入れるもの |
| --- | --- | --- |
| 1 日 | ちびピクセ | — |
| 3 日 | スカーフの ピクセ | 首に水色のスカーフ |
| 7 日 | マントの ピクセ | 両わきにピンクのマント（実績「おおきく なったね」） |
| 14 日 | きんの アンテナの ピクセ | アンテナが金色に |
| 30 日 | でんせつの ピクセ | まわりでドットのかがやきが入れかわる（点滅はしない） |

- 育った日は、あいさつのあとに「……からだが あったかい……！」「◯◯を てにいれた！」と言い、少しあとでパワーアップの音が鳴る
- 成長の重ね絵は、帽子の下に描く。箱の中・冒険・ファビコン・スタッフロール・認定証・日記のピクセにも反映される

### 気持ち（前に来た日からの日数）

| あいだ | ピクセ |
| --- | --- |
| 同じ日・1〜2 日 | いつもどおり |

- すねたまま帰っても、次に来たときもすねている（仲直りするまで続く）

### 記念日

初めて会った日から数えて 7・30・50・100・200・300 日目、それ以降は 100 日ごと、そして 1 年ごとに、あいさつのあとで「きょうで であって ◯にち！ いつも ありがとう。」（1 年ごとは「◯ねん」）。

## サウンド

- すべて Web Audio API で生成（音源ファイルなし）。PRESS START を押すまで何も鳴らさない
- **BGM**：140 BPM、Am → F → C → G の 4 小節ループ。メロディ（矩形波）、ベース（三角波）、裏拍のハイハット（ノイズ）
- タブが裏に回ると音全体を一時停止し、タブ名を「PAUSE ⏸ warpix-link」にする
- 冒険のジャンプはミニゲームのショット音、ボタンへの着地はカーソルを乗せたときの音を使う

## 動きを減らす設定のとき

OS で「視差効果を減らす / アニメーションを減らす」を設定していると、次のように変わります。

- 星は止まった状態で表示。ワープしても加速しない
- 登場アニメーションはすぐ終わる。点滅・ゆれ・ジャンプ・居眠りの Z もなし
