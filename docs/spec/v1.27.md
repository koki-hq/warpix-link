## なぜ

WARPIX は「ワープ」の なまえなのに、ピクセは リンクの となりで あそんでいる だけだった。リンクを おす こと（このページの いちばん だいじな こと）と ピクセを つなぐ。

## リンクを おしたとき（とびこむ）

- リンクは **いつもどおり すぐ ひらく**（クリックを とめない。ここは かざりだけ）
- おした リンクの みぎはし（右から 72px）に ワープあな（14×6 ドット、56×24px、シアンと ピンクの わ）が ひらく（180ms）
- はこの ピクセが いなくなり（`npc.setAway(true)`。はこには「るす」）、コピーが 弧を えがいて あなへ とびこむ（650ms、まわりながら ちいさく、`steps(14)`）。音は `powerup`
- とびこんだら あなが とじる
- とびこまない とき：うごきを へらす（OS の せってい・せってい画面）、シンプルモード、もう でかけている、ぼうけん中・タブ旅行中（`npc.isAway()`）、ピクセが みえない とき
- れんだしても とびこむのは 1 かい。リンクの ワープ（点数・星）は いままでどおり まいかい

## もどってきたとき（でてくる）

- このタブが かくれて（`visibilitychange`）、また みえたら 400ms あとに、おした リンクの うえに あなが ひらいて ピクセが とびだし、弧を えがいて はこへ もどる（650ms）。音は `coin`
- リンクが みえない ときは、あなを ださずに はこへ もどる
- おみやげばなし（せかいごとに ランダム）：

  - INSTAGRAM「ただいま！ しゃしんの せかいは\nきらきら していたよ。」「ただいま！ ぼくも しゃしん\nとって もらえば よかったな。」
  - BOOTH「ただいま！ おみせの せかいで\nほしい ものが いっぱい あった。」「ただいま！ ドットの グッズ、\nつい ながめちゃった。」
  - TUMBLR「ただいま！ TUMBLR の せかいは\nふしぎな え が いっぱい。」「ただいま！ むこうは しずかで\nちょっと ねむく なった。」
