## きまり（ユーザーと きめた こと）

- リンクは **いつも 6 こ**。ふえも へりも しない
- さいしょは いつもの 6 こ（YOUTUBE・TWITTER (X)・INSTAGRAM・BOOTH・TUMBLR・SPOTIFY）
- えらべるのは、こちらで よういした 公式の トップページだけ。**自由に URL は いれられない**
- アイコンは ぜんぶ 12×12 の オリジナルの ドット絵（公式ロゴは つかわない）

## たな（28 こ）

| たな | カセット |
| --- | --- |
| いつもの | YOUTUBE・TWITTER (X)・INSTAGRAM・BOOTH・TUMBLR・SPOTIFY |
| SNS・あつまる | TIKTOK・DISCORD・THREADS・BLUESKY・PINTEREST |
| おんがく | YOUTUBE MUSIC・APPLE MUSIC・SOUNDCLOUD |
| みる・あそぶ | ニコニコ動画・TWITCH・STEAM・PIXIV |
| つくる・とどける | NOTE・SUZURI・SKEB・GITHUB・CANVA |
| べんきょう | STUDYPLUS・スタディサプリ・DUOLINGO・QUIZLET・WIKIPEDIA |

- URL は `cassette.js` の `LIST`（ぜんぶ https、かぶりなし）
- いれなかった もの：おとな むけの さくひんが ある サイト（ピクセの いる ページに あわない）。LINE（ブラウザで ひらく 公式の いきさきが ない）
- あたらしい 22 こには、ゆびさした ときの ピクセの しょうかい（`hi`）と、ワープから もどった ときの おみやげばなし（`back`）が ある。いつもの 6 こは `extras.js` と `warp.js` に もとから ある

## いれかえかた

- リンクの した（フッターの うえ）に「⇄ リンクを いれかえる」（DotGothic16、13px、点線の したせん）。シンプルモードでも でる
- まど「カセット えらび」
  - うえ：いまの 6 こ（スロット、3 れつ）。たなを スクロールしても うえに のこる（`position: sticky`）
  - した：たなごとの カセット。もう はいっている カセットは 点線の わくと、はいっている ばんごう（きんいろ）
  - スロットを えらぶ（ピンクの わく。さいしょは 1 ばんめ）→ たなの カセットを おす → その スロットに はいる
  - もう ほかの スロットに ある カセットを おすと、2 つが **いれかわる**（いつも 6 こ、おなじ ものは ない）
  - 「いつもの 6 こに もどす」
  - メッセージ：「◯ばんめに なにを いれる？」「◯ばんめを ◯◯ に した。」「◯◯ は もう ◯ばんめに はいってるよ。」「いつもの 6 こに もどした。」
- いれかえると すぐ ページの リンクが かわる。実績「カセット こうかん」、にっき（1 日 1 かい、`cassette`）「リンクに ◯◯ の カセットを いれた。」、できごと `cassette`

## ほぞん

- `warpix-cassette`：6 この ID の ならび。いつもの 6 こと おなじ ときは けす
- よみこむ とき、6 こで・ぜんぶ しっている ID で・かぶりが ない ときだけ つかう（ちがえば いつもの 6 こ）
- `cassette.js` は `script.js` より さきに よむので、ページを かく まえに さしかわる（いつもの リンクが ちらっと みえない）
- 「このページについて」の のこすものに「えらんだ リンクの カセット」

## ほかと つながる ところ

- ゆびさした ときの しょうかい（`extras.js`）、おきにいりの かいすうと ハート（`favorite.js`）は、カセットを いれかえても そのつど リンクを よみなおす
- ワープ ダイブの おみやげばなしは、カタログの `back` を つかう
- ゆめ・おみくじ・おるすばんの え は、もとから そのとき ページに ある リンクを よむ

## テスト（`tests/cassette.test.mjs`）

1. さいしょは いつもの 6 こ、TWITTER は x.com と「(X)」、ほぞん なし。カタログは 28 こ、URL は https で かぶらない、アイコンと セリフが そろっている
2. スロットを えらんで いれる・もう ある カセットとの いれかえ・ほぞん・ひらきなおしても のこる・もとに もどす（ほぞんが きえる）。実績・にっき・フォーカス
