# 仕様メモ（バージョン別）

各バージョンが「何を・いつ・どれだけ」するかのメモです。どれも、その時点のタグのコードを見ながら書いています。

| バージョン | 名前 | 中身 |
| --- | --- | --- |
| [v1.4](v1.4.md) | 最高の踊り | 季節イベント、本物の天気、アプリ化とオフライン、コントローラー、ほかの訪問者と同じ空 |
| [v1.3](v1.3.md) | ページの外まで遊び場 | ページを跳びまわる冒険、タブをこえるピクセ、生きているファビコン、本物の月、印刷すると認定証、デモプレイ、スタッフロール、きせかえ |
| [v1.2](v1.2.md) | アーケード | ミニゲーム、実績 20 個、隠しコマンド、マザーシップ、流れ星、コンボ、居眠り |
| [v1.1](v1.1.md) | ピクセ登場 | マスコット、スコア、ワープ演出、UFO、隠しワープゾーン |
| [v1.0](v1.0.md) | シンプル版 | PRESS START、ドット絵アイコン、流れる星、チップチューン BGM |

いちばん上が最新（公開中）です。過去のバージョンは `git switch --detach v1.0` のように切り替えると手元で見られます。

## 新しいバージョンを作るとき

1. 前のバージョンのメモをコピーして `vX.Y.md` を作る
2. 冒頭に「タグ・ひとこと・前後のリンク」と「前のバージョンからの変更」を書く
3. 変わった数値や動きを直す
4. 前のバージョンのメモに「次のバージョン」へのリンクを足し、この表のいちばん上に1行足す
