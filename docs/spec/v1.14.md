## ミニゲームのボス

- **いつ**：ウェーブ 3・6・9……（3 の倍数）は、ふつうの敵の代わりに **マザーシップ**（48×20）が 1 機
- **体力**：20 ＋ ウェーブ×2。上に体力バー。当たると白く光る
- **動き**：左右に往復（速さ 0.5 ＋ ウェーブ×0.05）。扇形に 3 発ずつ撃つ（間隔 80 − ウェーブ×4 フレーム、最短 36）
- **点数**：1 発 10×ウェーブ、たおすと 500×ウェーブ ＋ ウェーブクリアの 100×ウェーブ
- **イベント**：たおすと `game-boss { wave }`（デモプレイでは出ない）。実績「ボス げきは」と、ピクセの日記「ミニゲームの ボスを たおした！」
- デモプレイの自動操縦は、ボスがいるときは ボスの下を ねらう

## 読み上げ

- 外へ出る 7 つのリンクに、見えない文字「（あたらしい タブで ひらく）」
- お気に入り・おみくじで使うリンクの名前は、共通の `linkLabel()`（ボタン自身の文字だけ）で取り出す。読み上げ用の文字やハートが名前に混ざらない
