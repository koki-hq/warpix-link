## 放っておかれたら、ページごと眠る

開きっぱなしのタブ（とくにスマホ）が、ずっと電池を使わないようにするためです。

| だれも触らずに | 起きること |
| --- | --- |
| 40 秒 | ピクセが寝る（これまでどおり） |
| さらに 20 秒 | デモプレイが始まる（これまでどおり。「動きを減らす」設定のときは始めずに、すぐ次へ） |
| デモプレイが 30 秒たつ | デモプレイを閉じて、**ページごと眠る** |

- **眠っているあいだ**：すべてのアニメーションを止め、背景の星も止め、ページを少し暗くする（不透明度 0.55）。UFO・流れ星・レイドは来ない（レイドは、起きたあとの回から参加できる）
- **起きる**：マウスを動かす・クリック・タップ・キー・ホイールのどれかで、すぐもとどおり。ピクセも「はっ！ ねてないよ！」と起きる
- 実績「だれも いない ゲームセンター」は、これまでどおりデモプレイが始まったときに取れる

## ドット絵の描きかた

`pixelSvg()` は、これまで 1 マスごとに `<rect>` を 1 つ作っていた。v1.6.1 からは、同じ色が横にならんだマスを 1 本の線にまとめ、色ごとに `<path>` を 1 つだけ作る。見た目は同じ。

- ページの部品（DOM の要素）の数：1,392 → 370（起動直後）

## テスト（tests/）

```sh
node tests/run.mjs            # ぜんぶ（34 件、約 6 分）
node tests/run.mjs adventure  # 名前に adventure を含むファイルだけ
```

- 必要なのは Node 22 以上と Chrome（自動でさがす。見つからなければ環境変数 `CHROME_PATH`）。ライブラリのインストールはいらない
- 音は鳴らさない（`--mute-audio`）。終わったら Chrome を確実に止める
- オンライン機能は切ったサーバーで動かすので、本物の Supabase（世界の記録）には触らない
- 天気・位置・コントローラー・Supabase はにせものを差しこむ。レイドは、同じページを 2 つ iframe でならべ、時計を「次の 5 分の 3 秒前」に進めて数秒で試す
- スクリーンショットは `tests/.output/`（git には入れない）

| ファイル | 試すこと |
| --- | --- |
| `core` | 起動・あいさつ、スタート直後のホバー、リンクと点数、BGM の保存、スマホで重ならない |
| `arcade` | 隠しコマンド、マザーシップ、ミニゲーム、実績画面、コナミコマンド、10 連打、放置→眠る→起きる、デモプレイ |
| `adventure` | おさそい、移動と着地、地面から戻れる、画面サイズを変えてもずれない、クリアとスタッフロール |
| `world` | タブ間の訪問、月、きせかえとファビコン、印刷の認定証、コピーに気づく |
| `device` | オフライン、季節イベント 4 つ、天気、コントローラー |
| `online` | 同じ空（浮かぶ・手を振る・回数・記録）、レイド |
| `grow` | 出会い、すねて仲直り、成長、大喜び、記念日、でんせつ、日記、`?date=` で保存しない |
| `simple` | `?simple=1`、スタート画面から入る、保存、戻る |
