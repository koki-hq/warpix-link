## じかんの そら

星の上（ページの中身の下）に、時刻で色が変わるうすいベールを重ねる。色は決めてあるパレット（紫・ピンク・シアン・かぼちゃ色）だけ。

| 時刻 | 空 | ベール（上 → 下） |
| --- | --- | --- |
| 20:00〜4:30 | よる | すきとおっている（いつもの夜空） |
| 4:30〜7:45ごろ | あさやけ | 紫 → ピンク |
| 7:45〜16:45ごろ | ひる | 少し明るい紺 → うすいシアン（星がうすくなる） |
| 16:45〜19:30ごろ | ゆうやけ | 紫 → かぼちゃ色 |

- となりの時刻の色へ、なめらかに混ぜる（1 分ごとに描きなおす）
- いまの空の名前を `html` の `data-sky`（`night` / `dawn` / `day` / `dusk`）に入れる
- **先取り**：URL に `?hour=18` のように付けると、その時刻の空になる（変わるのは空の色だけ。ピクセのあいさつなどは本当の時刻のまま）
- **出さない**：シンプルモード、ゲームボーイの色（`gameboy`）
- 雨や雪（天気・季節の演出）は、ベールの下に描く

## 図鑑：そらの いろ

| 名前 | 図鑑に入るとき |
| --- | --- |
| よる・あさやけ・ひる・ゆうやけ | その時間帯にページをひらいていたとき（ひらいたまま時間帯がかわっても入る） |

全部そろえるには、いろいろな時間に来る必要がある。

## テスト

`tests/sky.test.mjs`：`?hour=` で 6・13・18・23 時の空になり、色がつき（夜はすきとおる）、図鑑に入る。時刻の色はなめらかに変わる。シンプルモードとゲームボーイの色では出ない。
