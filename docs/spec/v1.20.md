## アプリの ショートカット

- ホーム画面に いれた アイコンを ながおし（パソコンは 右クリック）すると 3 つ：ミニゲーム（`./?go=game`）・さっきょく（`./?go=compose`）・おみくじ（`./?go=omikuji`）
- PRESS START の あと 1.2 びょう（うごきを へらす ときは 0.3 びょう）で ひらく。ほかの まどや ゲームが ひらいていれば なにもしない。しらない `?go=` は むし。シンプルモードでは スタートが ないので ひらかない
- オフラインでも ひらける（サービスワーカーは `?` の あとを みないで さがす）

## きゅうけい

- **かぞえかた**：15 びょうごとに、ページが みえていて、5 ふん いないに さわっていれば、そのぶん たす。10 ふんいじょう はなれたら（さわらない・うらに した）0 に もどす
- **50 ぷん** たまると、あいさつが おわって ほかの まどが ないときに「もう ◯ぷん いっしょに いるね。ちょっと めを やすめない？」［やすむ］［まだ だいじょうぶ］
  - **やすむ**：がめん いっぱいに「とおくを みてね」と 20 びょうの カウント（ピクセも めを とじる）。さいごまで みると「おつかれさま！ めが すっきり したね。」、実績「きゅうけい じょうず」、日記。0 から かぞえなおす
  - とちゅうで「おわる」・Esc・Enter：「また こんど やすもうね。」（実績なし）
  - **まだ だいじょうぶ**：20 ぷん あとに また きく
- 読み上げ：カウントの がめんは `role="status"`。はじめに「20びょう、とおくを みよう」、10 びょうで「あと 10びょう」。フォーカスは「おわる」へ
- シンプルモードでは かぞえない。記録は のこさない
