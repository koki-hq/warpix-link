## v1.57 からの変更

### シンプルモード（変更）
- スタート がめんの「リンクだけ みる ▶」と、いつもの がめんの みぎうえの SIMPLE を けした。いりぐちは かくしコマンド `simple`（と URL の `?simple=1`）だけ
- シンプルモードの ときだけ みぎうえに「▶ あそぶ」（もどる）
- ピクセの ガイドの「みぎうえの SIMPLE」の ひとことを けした。「このページについて」の せつめいも
- 「せってい」の「うごきを へらす」は のこす（こうりつ では なく、うごきで きぶんが わるく なる ひとの ため）

### リンク（変更）
- スタディサプリを たなから けした（27 こ）。パーティや いつもの 6 こに はいって いたら、いつもの 6 この まだ ない ものに おきかえる（`REMOVED`・`mend`）
- note と GitHub が スマホで アプリに ならない けん：しらべた。note の アプリが ひらく と とうろく して いるのは きじ（`/*/n/*` など）と ハッシュタグ だけで、トップ（`note.com/`）は ない。github.com には アプリで ひらく ための とうろく（apple-app-site-association）が ない。**アプリがわの とうろくの もんだいで、こちらからは なおせない**（アプリ せんようの アドレスは、アプリが ない ひとには エラーに なる ので つかわない）

### パーティ きりかえ（変更）
- 「◀ PARTY 1 ▶」を リンクの うえ から **リンクの した（「リンクの へんせい」の うえ）** へ。リンクの いちが v1.55 までと おなじに もどる
- スタート がめんでは みせない（ほかの ぶひんと おなじく、はじまって から でる）

### ぼうけん（変更）
- パーティ きりかえの だん（`.party-bar`）も あしば に（ないと うえに いけない、本人）
- スマホの そうさボタンを ホームバーの ぶん うえに（したから 32px）、すこし おおきく（56 → 62px）。ボタンの いちは v1.3 から かわって いなかった

### クローゼット（変更）
- わくは **ためして いる もの の きいろ 1 つ だけ**。きて いる ものは わくでは なく みぎしたに「きてる」の ふだ
- ゆびを のせた ひょうじ（hover）は マウスの ある たんまつ だけ（スマホでは おした あとも のこって、3 つめの わくに みえた）

### ピクセの へや（変更）
- ピクセや もの を おしても くろい わく（タップハイライト）を ださない
- ながおしで ✕ などの もじが えらばれない、コピーの メニューも ださない（へや・ステータス・みだし）

### ライセンス・ひみつの こうじょう（変更）
- **All rights reserved** に（`LICENSE`・README・「このページについて」）。公開の まま、みる ことは できるが ゆるしなく つかえない。v1.57 までの 版は MIT の まま

- ひみつの こうじょう：がめんは そのまま、「せっけいずを みる」（GitHub）を「**かくしコマンドを みる**」に（みたく ない ひとも いる ので、みたい ひと だけ）。おすと おなじ まどの なかで かくしコマンド集（うつ ことば と おきる こと、20 こ）、「こうじょうに もどる」。パソコンは キーボード、スマホは じっせきの CHEAT CODE
