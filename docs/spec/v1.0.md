## 構成

ビルドなし。`index.html`、`style.css`、`script.js` の3ファイルだけで動きます。

| ファイル | 役割 |
| --- | --- |
| `index.html` | タイトル、リンクボタン 6 つ、PRESS START 画面、BGM ボタン |
| `style.css` | 配色、ピクセル枠のボタン、走査線、アニメーション |
| `script.js` | アイコン描画、サウンド、流れる星、PRESS START |

## 画面

- **タイトル**：WARPIX-LINK（Press Start 2P、ピンクと黒のずらし影）
- **サブタイトル**：PRESS A LINK TO WARP_（`_` が点滅）
- **リンクボタン**：YouTube / Twitter / Instagram / BOOTH / Tumblr / Spotify。リンク先は各サービスのトップページ（仮）。新しいタブで開く
- **ボタンの反応**：カーソルを乗せると色が明るくなり、左に ▶ が点滅。押すと右下に 1 ドット沈む
- **BGM ボタン**：右上。BGM ON / BGM OFF
- **フッター**：© 2026 WARPIX
- **背景**：紺色の方眼（32px）＋走査線＋流れる星

## アイコン

- 12×12 マスの1色ドット絵を、JS の文字列（`#` が塗り）から SVG にして表示。ボタン上では 24px（1マス 2px）
- 色はシアン（`--accent-2`）
- YouTube（再生ボタン）、Twitter（鳥）、Instagram（カメラ）、BOOTH（バッグ）、Tumblr（t）、Spotify（音波）

## 起動の流れ

| 時間（クリック後） | できごと |
| --- | --- |
| 0 秒 | 起動ジングル。BGM 予約（0.8 秒後に開始） |
| 0〜0.45 秒 | PRESS START 画面が3回点滅して消える |
| 0.45 秒 | タイトルが上から落ちてくる（0.5 秒、4 コマ） |
| +0.5 秒 | サブタイトル・フッター・BGM ボタンが出る |
| +0.6 秒〜 | リンクボタンが 0.12 秒おきに1つずつ左から出る |

- PRESS START 画面はクリックでも Enter でもスタートできる（ボタンに最初からフォーカス）
- JavaScript が動かない環境では PRESS START 画面を出さず、最初から全部表示する

## 流れる星

- canvas に描画。数は画面の広さ ÷ 9,000（480×1000 なら約 53 個）
- 2 割が大きい星（4px、毎フレーム 0.6px 落下）、残りは小さい星（2px、0.2〜0.4px）
- 色は白 3 : シアン 1 : ピンク 1 の割合
- 位置は 2px 単位にそろえる。画面の下に出たら上から出直す

## サウンド

すべて Web Audio API で生成（音源ファイルなし）。PRESS START を押すまで何も鳴らしません。

| 音 | 中身 |
| --- | --- |
| 起動ジングル | ド・ミ・ソ（各 0.08 秒）→ 高いド＋低いドの三角波（0.4 秒） |
| カーソルを乗せる | 880Hz の矩形波を 0.05 秒 |
| リンクを押す | 440Hz → 1760Hz に上がる矩形波を 0.15 秒 |
| BGM | 140 BPM、Am → F → C → G の 4 小節ループ。メロディ（矩形波）、ベース（三角波、オクターブを交互に）、裏拍のハイハット（ノイズ） |

## ブラウザに保存するもの

| キー | 中身 |
| --- | --- |
| `warpix-bgm` | BGM の ON / OFF（`"on"` / `"off"`）。次に開いたときもこの状態で始まる |

## 動きを減らす設定のとき

- 星は止まった状態で表示
- 登場アニメーションはすぐ終わる。点滅（カーソル、▶、PRESS START）はしない
- 音はそのまま
