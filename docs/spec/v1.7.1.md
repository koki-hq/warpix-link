## このページについて

フッターの「このページについて」（シンプルモードでも出る）で、次のことを書いた窓が開く。

| 見出し | 中身 |
| --- | --- |
| このブラウザに のこすもの | スコア、実績、ピクセの成長と日記、よく行くリンク、帽子、BGM やシンプルモードの設定。このブラウザの中だけに保存し、どこにも送らない |
| そとに おくるもの | 天気：聞いて「いいよ」のときだけ、位置を約 10km に丸めて Open-Meteo へ。同じ空・レイド・世界の記録：ランダムな番号と帽子の種類、つついた回数などを Supabase へ（名前・位置・スコアは送らない）。文字：Google Fonts から読みこむ |
| ※ | GitHub Pages もふくめ、どのサービスも、つなぐときにふつうは IP アドレスを受けとる |
| つかっていないもの | 広告、アクセス解析、クッキー |
| きろくを けす | このブラウザに残した記録をぜんぶ消して、はじめからにする |
| つくったひと | WARPIX ／ いっしょに つくった：Claude、ソースコード（GitHub）へのリンク |

### きろくを ぜんぶ けす

- **1 回目**：ボタンが「ほんとに けす（もういちど おす）」に変わり、ピクセが「ほんとに？ ぼくとの きおくも きえちゃうよ……」。6 秒たつと元に戻り「……よかった。」
- **2 回目**（6 秒以内）：名前が `warpix-` で始まる記録だけをぜんぶ消し（ほかのサイトの記録には触らない）、「……はじめまして？」と言ってページを読みなおす。ピクセとは、また初めて会ったところから
- サービスワーカーが保存したページのファイルは消さない（記録ではないので）

## スマホの連打とダブルタップ拡大

すばやくタップする場所とボタン全般に `touch-action: manipulation` を付けて、ダブルタップで拡大しないようにした。2 本指でつまむ拡大（ピンチ）はそのまま使える。

- 対象：ボタンとリンク全般、レイドのマザーシップ、ピクセ（10 連打）、マザーシップ、UFO、空に浮かぶほかの人のピクセ、ふってくるピクセ、流れ星、会話ウィンドウ
- 連打する的は、長押しで文字が選ばれたり、タップのたびに色の四角（タップハイライト）が出たりしないようにした
- ヘッドレス Chrome ではダブルタップ拡大そのものを再現できないため、テストでは設定が効いていることを確かめている。実機での確認がいちばん確実
