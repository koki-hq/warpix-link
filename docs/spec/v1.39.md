## もとから あった もの（v1.3・v1.8）

ぼうけんの タイマー（右上）、日がわりの「きょうの コース」（コインと UFO の 置き場所が 日付で きまる）、ゴースト（その 日の ベストの 走り）、スタッフロール。RTA は これに カードと はやさくらべを たした もの。
※ 足場は ページの ボタンや タイトル なので、**画面の 大きさで コースの 形が かわる**。カードに 画面の しゅるい（SMARTPHONE ／ PC、はば 700 未満が スマホ）を かく。

## きろくカード

- クリア（`adventure-clear`）の あと、ピクセが ひまに なって ほかの まど（スタッフロール・dialog・ポストカード）が ない ときに「きょうの きろく、カードに する？」→「つくる」／「いい」（60 びょう まって ひまに ならなければ きかない）
- 1200×630 の 画像（ポストカードと おなじ 大きさ）：うえと したに ゴールの はたの チェック、ピクセ（いまの 姿と 帽子）、「PIXE RTA」、`COURSE 2026-10-18`、タイム（きいろ、96px）、ゴーストに かった 差・じこベスト・おなじ そらの きょうの いちばん、ひだり したに 画面の しゅるいと `#ピクセRTA`、みぎ したに `link.warpix.app`
- まど：ほぞん（`warpix-rta-<日付>.png`）・シェア・とじる。実績「ピクセ RTA」、にっき「ぼうけんの きろくカードを つくった。<タイム>。」
- クリア まえに ひらくと「きょうは まだ ぼうけんを クリア してないよ。」

## ほぞん（`warpix-rta`）

- `{ course, best, device, ghostDiff, sky }`。**その 日の ぶん だけ**（日付が かわると あたらしく）
- `best` は その 日の いちばん はやい タイム（おそい クリアでは かわらない）。`ghostDiff` は その とき の ゴーストとの 差
- `?date=` で のぞいて いる ときは ほぞん しない

## おなじ そらの はやさくらべ（オンラインの ときだけ）

- その 日の じぶんの ベストが でたら、`online.send("rta", { course, time })`（ランダムな ばんごう いがい、なまえは おくらない。データベースには のこらない）
- うけとった タイムが きょうの コースで、3〜600 びょうの あいだで、いままでの「おなじ そらの きょうの いちばん」より はやければ おぼえて、ピクセが「おなじ そらの だれかが きょうの コースを <タイム> で クリア！」（ぼうけん・ゲーム中・シンプルモード・しゃべって いる ときは だまって おぼえる だけ）
- じぶんの タイムも「おなじ そらの きょうの いちばん」に はいる

## テスト（`tests/rta.test.mjs`）

1. クリアすると きいて「つくる」で カード（まどの なまえ・ほぞんの なまえ・画像の 説明に タイム）、実績、ほぞん。おそい タイムでは かわらず、はやい タイムで かわる
2. カードの 画像は 1200×630 で、タイムの ところに 文字が ある
3. おなじ そらの タイム：はやい ときだけ ピクセが いって おぼえる。おそい・ちがう 日・ありえない タイムは むし
4. クリア まえは「まだ」。`?date=` では ほぞん しない
