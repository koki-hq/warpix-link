## わたす

- カセット えらびの まどの したに「この 6 こを おすそわけ」（「いつもの 6 こに もどす」と ならぶ）
- URL：`このページ?cassette=id,id,id,id,id,id`（例：`?cassette=tiktok,discord,ytmusic,studyplus,duolingo,niconico`）
- スマホの きょうゆう（`navigator.share`）が あれば それで。タイトル「WARPIX-LINK の カセット」、ことば「ぼくの 6 この リンク、つかってみて！」→「おすそわけ したよ。」
  - じぶんで やめた とき（AbortError）は なにも いわない
- きょうゆうが ない とき：クリップボードに コピー →「URL を コピーしたよ。ともだちに おくってね。」。コピーも できない ときは「この URL を おくってね：（URL）」
- 実績「カセットの おすそわけ」
- この ページが どこかへ おくる ものは ない（わたすのは つかう 人）

## もらう

- `?cassette=` が 6 こで、ぜんぶ しっている ID で、かぶりが ない ときだけ きく。いまと おなじ 6 こなら きかない
- `?cassette=` は すぐ URL から けす（ほかの パラメータは のこす）。ひらきなおしても なんども きかない
- いつもの ページは PRESS START の 0.6 びょう あと、シンプルモードは すぐ、まど「カセットの おすそわけ」
  - 「ともだちから 6 この カセットが とどいたよ。いまの リンクと いれかえる？」と、とどいた 6 こ（ばんごう・アイコン・なまえ）
  - 「いれかえる」：いれかえて ほぞん、実績、にっき（1 日 1 かい、`cassette-gift`）「ともだちの カセットを いれた。」
  - 「いまの まま」・✕・Esc：なにも かえない

## テスト（`tests/cassette-share.test.mjs`）

1. とどいた URL：すぐ URL から けす、PRESS START の まえは きかない、あとで きく（6 こ みえる）、きく まえは かわらない、「いれかえる」で いれかわり ほぞん・実績・にっき
2. 「いまの まま」で かわらず、ひらきなおしても きかない
3. 5 こ・しらない ID・かぶり・いまと おなじ は きかず URL から けす。シンプルモードは すぐ きいて、`?simple=1` は のこす
4. おすそわけ：きょうゆうに いまの 6 この URL、メッセージ、実績。きょうゆうが ない ときは コピーか URL を みせる
