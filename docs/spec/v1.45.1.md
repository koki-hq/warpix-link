## リハーサル（`tests/launch.test.mjs`）

ホームページの `tools/open-news.json` と おなじ「WARPIX製作所、開店しました」を わたし、にせの オンラインと ずらした 時計で。

1. **開店の 朝（1きせい）**：8 時に ひらくと、あいさつで「とくべつな てがみ」の しらせと「こんや 21じ」の 予告、ひまに なると「WARPIX製作所から おしらせ！『WARPIX製作所、開店しました』」。てがみは 開店の 日の ことば、製作所だよりに NEW
2. **開店の 夜（SNS から はじめて 来た 人、ほかに 2 にん）**：1きせいの ものは なにも ない、予告は ある。21:00 に HP 270/270 の だい マザーシップ、みんなで たおすと「3にんで のりきった」、3 この ほしの せいざ、きねんしゃしんに さそわれて しゃしん
3. 開店の おしらせの 題の 文字が ぜんぶ ドットの もじ（`fonts/chars.txt`）に ある

※ 本物の Supabase・本物の ホームページの 自動の おしらせは、11/1 の 当日 まで ためせない。当日は 7:00 すぎに https://warpix.app/news.json に `2026-11-01-open` が あるか、warpix-link の 製作所だよりに NEW が でるかを みる
