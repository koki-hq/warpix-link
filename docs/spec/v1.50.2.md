## v1.50.1 からの変更

- **なおし（rta.js・opening.js・device.js・compose.js）**：ピクセの 質問を ことわると、質問の ことばが のこった ままに なって いた（本人「記録残す？で『いい』に すると セリフが そのまま」）。ことわると「わかった！」（とどいた きょくは「じゃあ また あとでね。」）。きろくカード・きねんしゃしん・ホーム画面に つれていく・とどいた きょく の 4 つ。ほかの 質問は もともと ひとこと いって いた
- **なおし（script.js・style.css）**：ワープや アプリ切りかえから もどると、BGM が ON なのに しずかだった（本人「バグなのかなって 不安」）。iPhone は タップするまで 音を おこさせて くれない（音ダブりの 対応 v1.47.2 で もどる たびに 音の そうちを つくりなおす ため）。そこで、もどって **0.5 びょう たっても 音が おきて いなければ、BGM ボタンが ピンクで「BGM TAP!」と 点滅**（動きを へらす 設定では 点滅しない）。どこを タップしても 音が もどり、ボタンも「BGM ON」に もどる。「TAP」の ときに ボタンを おしても OFF には ならない
- **なおし（weather.js）**：位置情報の 許可が 1 日に なんども 出た（本人「許可してるのに 1 日 2 回」）。iPhone の ホーム画面の アプリは 許可を すぐ わすれる ので、てんきを とりなおす たび（30 ぷん）に ばしょを ききに いって いた。**やく 10km に まるめた ばしょを 1 にち（24 じかん）つかいまわす**。てんきは いままで どおり 30 ぷんごとに とりなおす。ばしょは `warpix-weather-cache` に `lat`・`lon`・`placeAt` と して いっしょに のこす（あたらしい キーは ない）
- **なおし（script.js）**：Spotify の 音量が きかなく なった 件（本人「WARPIX の せい？」、たしかでは ない）。iPhone に `navigator.audioSession.type = "ambient"` を つたえる。BGM は 背景の 音と して、ほかの アプリの 音を とめたり、音の つかいかたを うばったり しない。**かわりに マナーモードでは 鳴らない**。audioSession が ない ブラウザでは なにも しない
- **なおし（postcard.js・rusuban.js）**：ポストカード・きろくカード・おみやげの えが 写真に 保存 できなかった。iPhone の ホーム画面の アプリでは ふつうの ダウンロードが 写真に はいらない。**スマホ（pointer: coarse）で 画像を 共有できる ときは「ほぞん」で 共有の まどを ひらく**。文や URL は つけない（つけると「画像を 保存」が でない ことが ある）。そこで「画像を 保存」を えらぶと 写真に はいる。パソコンでは いままで どおり ダウンロード。`postcard.saveLink(a, blob, name)`
- **変更（index.html）**：このページについて の「ブラウザに のこす もの」に「てんきと やく 10km に まるめた ばしょ（1 にち つかいまわす ため）」
- **テスト**：`day-use` を 4 件（ことわった あと・BGM TAP・ばしょの つかいまわし・スマホの ほぞん）
- **変更**：サービスワーカーのキャッシュ名を `warpix-v1.50.2` に
- 実績 70 個（かわらず）・テスト 192 件（4 件 たして）
- **テスト**：`adventure` の「同じ日はコースが同じ」は、まいかい きろくを けして はじめての 人と して くらべる。2 かいめは ピクセの あいさつが かわる（v1.50 なれ）ので、足場の 高さが 6px ずれて こけて いた（v1.50.1 の main でも おなじ。サイトの ふぐあい では ない）
