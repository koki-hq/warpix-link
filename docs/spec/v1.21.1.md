# warpix-link 仕様メモ v1.21.1「テストを 同時に」

- **タグ**：`v1.21.1`（2026-10-16）
- **ひとこと**：テストを 4 つ同時に ながして、16 分 → 5 分。サイトそのものは かわらない
- **前のバージョン**：[v1.21](v1.21.md) ／ [バージョン一覧](README.md)

ここには v1.21 から変わったところだけを書きます。

## v1.21 からの変更

- **変更**：`tests/run.mjs`（同時に ながす）、`tests/lib/harness.mjs`（Chrome の ポートを ワーカーごとに わける `WARPIX_PORT_BASE`）
- サイトの ファイルは かわらないので、サービスワーカーのキャッシュ名（`warpix-v1.21.0`）は そのまま

## テストの ながしかた

| コマンド | なにを する |
| --- | --- |
| `node tests/run.mjs` | ぜんぶ。CPU の かずの はんぶん（さいだい 4）の ワーカーで 同時に |
| `node tests/run.mjs sky` | 名前に `sky` を含む ファイルだけ |
| `node tests/run.mjs --jobs 1` | 1 つずつ 順番に（前と おなじ。いちばん安定） |
| `node tests/run.mjs --jobs 6` | ワーカーの かずを きめる |

- **わけかた**：テストの ファイルが 大きい じゅんに、いちばん すいている ワーカーへ（大きい ファイルは だいたい 長く かかる）
- **ワーカー**：それぞれ べつの Node の プロセス。Chrome の ポートは 9400 ＋ 150×番号 から。終わった ファイルから 結果を だす（ならびは ファイル順では ない）
- **さいご**に、こけた テストだけ もういちど まとめて だし、`88 passed, 0 failed (296s, 4 並列)` のように しめす。とちゅうで ワーカーが とまって 結果が こなかった ファイルも「こけた」に かぞえる
- 音は 鳴らさない・本物の Supabase に さわらない・Chrome を のこさない は これまでどおり

## はかった 時間（この PC、16 スレッド）

- 1 つずつ：約 16 分（984 びょう）
- 4 つ同時：約 5 分（296・299 びょう）、2 かい とも 88 件 ぜんぶ 通った
