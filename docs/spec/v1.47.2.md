# warpix-link 仕様メモ v1.47.2「しずかな そら」

- **タグ**：`v1.47.2`（2026-10-19）
- **ひとこと**：iPhone の ホーム画面アプリで、リンクから もどった あとや ほかの ピクセを タップした あとに、ゆっくりで くずれた BGM が とまらなく なる 件を なおした（ユーザーの 気づき）。あわせて、ひらきっぱなしで 裏に いる 人は 空から きえる ように した（開店の よる 11/1 の しゅうらいの よるで、見ていない 人の ぶんまで マザーシップが かたく ならない ように）
- **前のバージョン**：[v1.47.1](v1.47.1.md) ／ [バージョン一覧](README.md)

## v1.47.1 からの変更

- **変更（script.js の 音）**
  - 画面に もどったら（`visibilitychange` で 見える ように なったら）、音の そうち（AudioContext）を すてて つくりなおす。BGM・曲・テンポ・音量は ひきつぐ（作曲画面の 再生位置だけ 頭から）。iPhone では リンク先で 動画などが 音を つかうと、もどった あとに「チャリン」などの 音が ゆっくり・かさなって くずれ、BGM オフでも なりつづける ことが あった。共通項は「もどった あとに 音を 1 つ ならす」こと（ワープから もどる チャリン、ほかの ピクセに てを ふる チャリン）
  - つくりなおした 音の そうちが タップを まって いる ときは、つぎの タップで おこす（BGM は 最初の タップから）
  - 裏に いる ページ（`document.hidden`）は 音を おこさない。だれかに てを ふられても、レイドの 合図が きても、その 人の ポケットで BGM が なりださない
  - iPhone の「interrupted」の じょうたいでも おこす（いままでは「suspended」だけ）。おこす・とめる の しっぱいは だまって うけとめる
- **変更（online.js の そら）**
  - 空（Presence）に うかぶのは、いま 画面を 見て いる 人 だけ。裏に まわったら `untrack`、もどったら `track`（ぼうしも あたらしく）。裏で ぼうしを かえても 空には もどらない
  - 合図（レイド・RTA・てを ふる）は 裏でも うけとりつづけるので、もどったら すぐ おいつく
  - えいきょう：ONLINE の 人数、レイドの HP（見て いる 人数 × 1 人ぶん）、開店の よるの 星座と きねんしゃしんに はいるのは、その とき 見て いる 人。ちょっと 通知を 見る だけでも ピクセは いったん きえて、もどると また うかぶ
- **テスト**：`online` に「見ていない画面は空から消え、裏では音を起こさない。もどると音の装置を作りなおす」（裏に まわると untrack・てを ふられても チャリンや BGM を 呼んでも 音の そうちは ふえず おきない・裏で ぼうしを かえても track しない・もどると track と 音の そうちの つくりなおし・BGM は つづく）。にせものの Supabase は track と untrack の 回数を かぞえる
- **変更**：サービスワーカーのキャッシュ名を `warpix-v1.47.2` に
