## 「ホームがめんに いれる」

- ばしょ：「このページについて」の さいしょの せつめいの すぐ した（開店の とき、紹介文と いっしょに「ここを みてね」と いえる ように）
- ひとこと（まどを ひらく たびに）：
  - アプリで ひらいて いる（`pocket.standalone()`）→「いまは ホームがめんの アプリで ひらいているよ。」
  - それいがい →「アプリに すると、ひらくのが はやく なって、きろくも きえにくく なるよ。」
- やりかた（3 つ ぜんぶ だす）：
  - iPhone・iPad（Safari）：したの きょうゆうボタン（□に↑）→「ホーム画面に追加」→「追加」
  - Android（Chrome）：みぎうえの メニュー（︙）→「ホーム画面に追加」か「アプリを インストール」
  - パソコン（Chrome・Edge）：アドレスバーの みぎはしの インストールの マーク
- いまの きかい：iPhone・iPad（UA、または MacIntel で タッチ あり）／ Android（UA）／ それいがいは パソコン。その だんを シアンに して、見出しに「（この きかい）」（きいろ）
- ボタン「ホームがめんに いれる」：ブラウザの `beforeinstallprompt` を おぼえて いる ときだけ。おすと ブラウザの いれる まどが でる（v1.4 の `pocket.install()`）
- iPhone の ちゅうい（iPhone で、アプリで ひらいて いない とき）：「iPhone では、ホームがめんの アプリと Safari で きろくが べつべつ です。いまの きろくを アプリに もっていくには、したの「ふっかつの じゅもん」を コピーして、アプリの ほうで はってね。」（v1.36.1 の ひっこしで わかった こと）

## テスト（`tests/home-guide.test.mjs`）

1. パソコンでは パソコンに しるしと「（この きかい）」、ひとこと、ボタンは `pocket.canInstall()` と おなじ（ヘッドレスの Chrome も ほんとうに いれられると いう ことが ある）、iPhone の ちゅういは ださない
2. iPhone の UA では iPhone に しるしと ちゅうい
3. Android の UA と にせの `beforeinstallprompt` で ボタンが でて、おすと `prompt()`、いれた あとは きえる。`navigator.standalone` の iPhone では「アプリで ひらいているよ」、ちゅういは ださない
