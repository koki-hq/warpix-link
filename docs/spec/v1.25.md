## なぜ

きろくは ぜんぶ ブラウザの なか（ユーザー登録なし）。キャッシュを けすと きえるし、iPhone の Safari は ホームがめんに いれずに 7 日 ひらかないと けす ことが ある。
登録なしの まま、きえても もどせる・ひっこせる ように する。

## きえにくく する

- `navigator.storage.persist()`（ブラウザに「けさないで」と おねがい）。じゅもんを つくった とき（ボタンを おした とき）と、ホームがめんの アプリで ひらいた とき
  - Firefox は たずねる まどを だすので、ふつうの ページを ひらいた だけでは よばない
- きいている ときは「この ブラウザには「けさないで」と おねがい ずみ。それでも、キャッシュを けすと きえます。」

## ピクセの ひとこと（いちどだけ）

- 会った 日が 3 日 いじょう、ホームがめんの アプリでは ない、「けさないで」が まだ、シンプルモードでは ない とき、あいさつの あとに
  - 「ねえ、ぼくの きおくは この ブラウザの なかに\nしまってるんだ。けされたら、わすれちゃうかも……」
  - iPhone・iPad：「ホームがめんに いれて ひらくと、きえにくく なるよ。\n「このページについて」で ふっかつの じゅもんも つくれる。」
  - ほか：「「このページについて」で、ふっかつの じゅもんを\nつくっておくと あんしんだよ。」
- いったら `warpix-save-told`

## ふっかつの じゅもん

- **なかみ**：`warpix-` で はじまる きろく ぜんぶ（`warpix-lastseen` と `warpix-moved` は のぞく）を `{ v: 1, at: "YYYY-MM-DD", data: { key: 文字列 } }` に して、`deflate-raw` で ちぢめて、base64url に。あたまに `WARPIX1-z`（ちぢめない ブラウザは `WARPIX1-j`）
- **つくる**：「じゅもんを コピー」（クリップボード。だめな ときは わくに だして えらぶ）、「ファイルに ほぞん」（`warpix-save-YYYY-MM-DD.txt`）。実績「ふっかつの じゅもん」
- **いれる**：わくに はって「ふっかつ する」、または「ファイルから よむ」。空白や 改行は むし
  - まちがい（あたまが ちがう・こわれている・`warpix-` いがいの きろくが ある）：「……じゅもんが ちがいます。」なにも かわらない
  - 1 かいめ：「YYYY-MM-DD の きろくだね。\nいまの きろくは きえて、いれかわるよ。いい？」（10 秒で もとに もどる）
  - 2 かいめ：いまの `warpix-` を ぜんぶ けして、じゅもんの きろくを いれ、`warpix-moved` を つけて 読みこみなおす
- **ひっこした あと**：あいさつに「……おもいだした！ ひさしぶり！\nひっこし、おつかれさま。」、日記に「ひっこしの ひ。ふっかつの じゅもんで、あたらしい ブラウザに きた。」
- どこにも おくらない（ブラウザの なかで つくって、なかで よむ）
