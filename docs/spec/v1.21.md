## ぼうし アトリエ

- **ひらきかた**：じっせきの まど（トロフィー）の WARDROBE の となり「＋ ぼうしを つくる」、または ひみつの ことば `atelier`
- **マス**：16×6（ピクセの え の うえ 6 だん）。ピクセの あたまの ばしょは、からっぽの マスを うすく みせる。みぎに かぶった ときの みほん
- **いろ**：しろ・ピンク・みずいろ・きいろ・くろ・けしゴム（ファビコンでも かける いろだけ）
- **かきかた**
  - マウス・タッチ：マスを おすと ぬる。おなじ いろの マスを おすと けす。ドラッグで つづけて ぬれる
  - キーボード：マスは 1 つだけ Tab で とまり、やじるし・Home/End で うごく。スペース/Enter で ぬる・けす。いろは ←→↑↓
  - 読み上げ：マスは「◯だんめ ◯ばんめ：いろ」
- **なまえ**：10 もじまで（からなら「じぶんの ぼうし」）
- **かぶる**：なにも かいていなければ かぶれない。かぶると ほぞんして WARDROBE に ならび（ID `mine`）、すぐ かぶる。ファビコン・ポストカード・ずかんの ぼうしにも でる。実績「ぼうし デザイナー」と「おしゃれさん」、日記「ぼうし「◯◯」を つくって もらった。」。とじたら トロフィーへ フォーカスを もどす
- **ほぞん**：`warpix-myhat`（`{ name, rows }`）。かたちが ちがう データは よみこまない
