# warpix-link 仕様メモ v1.31「ワープを はやく」

- **タグ**：`v1.31`（2026-10-17）
- **ひとこと**：PRESS START が みえるまで 2.5 びょう → 1.5 びょう（おそい スマホの 回線で）。みためは そのまま
- **前のバージョン**：[v1.30.1](v1.30.1.md) ／ **次のバージョン**：[v1.32](v1.32.md) ／ [バージョン一覧](README.md)

ここには v1.30.1 から変わったところだけを書きます。

## なぜ

WARPIX は「ここを とおって 公式サイトへ いく 踏み台」なので、いちばん だいじなのは おせるまでの はやさ。
v1.0 から あそびを たしつづけて、スクリプトが 34 こに なっていた。

## はかった こと（遅めの 4G：150ms・1.6Mbps、CPU 4 倍おそく。3 かいずつ）

| ためした こと | FCP | PRESS START が みえた | DOMContentLoaded |
| --- | --- | --- | --- |
| v1.30.1 のまま | 2416〜2664 ms | 2422〜2615 ms | 3108〜3224 ms |
| フォントの CSS を またない（`media="print"`） | 2552〜2604 ms | − | − |
| **スクリプトを defer** | **1456〜1496 ms** | **1429〜1472 ms** | 3285〜3342 ms |

- フォントは かわらなかったので そのまま。defer に した
- ぜんぶ よみおわる じかん（DOMContentLoaded）は ほぼ おなじ。さきに みえる ように なった ぶんだけ はやい

## かえた こと

- `index.html`：`config.js` と `cassette.js` いがいの スクリプト 32 こに `defer`（じゅんばんは そのまま）
  - `cassette.js` は すぐ よむ。えらんだ リンクに、かく まえに さしかえる ため（いつもの リンクが ちらっと みえない）
- `script.js`：PRESS START が みえてから のこりの ファイルが そろう まで（いまは やく 1.9 びょう）に おされたら、ボタンを「NOW LOADING...」に して、そろって（DOMContentLoaded）から はじめる
  - defer の ファイルが うごいている あいだ `document.readyState` は もう `"interactive"` なので、`DOMContentLoaded` を じぶんで おぼえて みる
  - じつは v1.30.1 まえにも 0.7 びょうくらい おなじ すきまが あって、そこで おすと あとの ファイルが「はじまった」合図（`boot`）を うけとりそこねていた。それも なおった
- シンプルモードの リンクは HTML だけで うごくので、スクリプトを またずに 1.5 びょうで おせる
- サービスワーカーのキャッシュ名を `warpix-v1.31.0` に（2 かいめからは いままでどおり キャッシュから すぐ）

## テスト（`tests/speed.test.mjs`、2 件。合計 124 件）

1. スクリプトは config.js・cassette.js だけ すぐ、ほかは ぜんぶ defer。じゅんばんは script.js から
2. まっさらな ブラウザで、さいごの ファイル（about.js）を わざと とめて おき、PRESS START を おすと「NOW LOADING...」で はじまらない。とおすと はじまって「PRESS START」に もどる
   - さきに いちど ひらくと サービスワーカーが ファイルを ためて しまい、とめられないので、いきなり ひらく
