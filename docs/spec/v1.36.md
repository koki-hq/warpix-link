## なぜ ひつようか

- ブラウザの きろく（localStorage）は じゅうしょ（オリジン）ごと。`koki-hq.github.io` の きろくは `link.warpix.app` からは よめない
- GitHub Pages に カスタムドメインを つけると、ふるい じゅうしょは あたらしい じゅうしょへ てんそう される。でも いちど ひらいた ひとは サービスワーカーが しまった ページが でる（ナビゲーションの てんそうは キャッシュに いれない、sw.js の こうしんも てんそうで しっぱい する）ので、**しまって ある 版の まま**に なる
- だから つなぎかえる **まえ**に この 版を しまわせて おけば、ふるい じゅうしょ（ホームがめんの アイコンも）を ひらいた とき この 版が でて、ひっこしを てつだえる

## ふるい じゅうしょ がわ

- `config.js` の `WARPIX_MOVE = { from: "koki-hq.github.io", to: "https://link.warpix.app/" }`。`location.host` が `from` の ときだけ うごく
- `to` の `manifest.webmanifest` を `cache: "no-store"` で よみ、`name` が あれば「あたらしい おうちが できた」。つなぎかえる まえ（GitHub の 404）・とどかない ときは なにも いわない
- PRESS START の あと（シンプルモードは すぐ）に まど：「あたらしい おうちが できたよ！ きろくを ぜんぶ もって、いっしょに ひっこそう。」＋ あたらしい じゅうしょ。「きろくごと ひっこす」／「あとで」
- 「きろくごと ひっこす」：`save.encode()` で じゅもんを つくり、`warpix-moved-out` を つけて、`<to>#move=<じゅもん>` へ。じゅもんは URL の `#` の うしろ なので サーバーにも おくられない
- もう ひっこした あと（`warpix-moved-out`）は「ぼくは もう あたらしい おうちに いるよ。」「あたらしい おうちへ」（じゅもん なしで いく）

## あたらしい じゅうしょ がわ

- `index.html` の さいしょの スクリプトで `#move=` を ひろい、**ほかの スクリプトが かきこむ まえに** `warpix-` の きろくが あったかを みて、`window.WARPIX_MOVE_IN = { code, had }`。URL から `#move=…` を けす
- `move.js` で `save.decode()`：
  - まっさら（`had` が false）→ きかずに `save.restore()` して よみなおす。つぎの あいさつは v1.25 の「……おもいだした！ ひさしぶり！ ひっこし、おつかれさま。」、にっきに「ひっこしの ひ」
  - もう きろくが ある → PRESS START の あとに「ふるい おうちから にもつが とどいたよ（<日付> の きろく）。この ブラウザの いまの きろくと いれかえる？」「いれかえる」／「いまの まま」
  - こわれた じゅもん → 「にもつが とちゅうで こわれちゃった…… ふるい おうちで ふっかつの じゅもんを コピーして、「このページについて」で いれてね。」（ボタンは「わかった」だけ）

## ひっこしの じゅんばん（事務所の `05-開店の計画.md`）

1. ホームページが `warpix.app` へ（さきに。製作所だよりの よみさきが そこに なるので）
2. この 版を いまの github.io に だす
3. つかう たんまつで いちど ずつ ひらいて、この 版を しまわせる
4. warpix-link の リポジトリに `CNAME`（`link.warpix.app`）、Pages の カスタムドメイン、HTTPS
5. ふるい じゅうしょを ひらく → ピクセの まど →「きろくごと ひっこす」。ホームがめんの アイコンは あたらしい じゅうしょで つくりなおす

## テスト（`tests/move.test.mjs`）

ポートの ちがう サーバー 2 つで ふるい・あたらしい じゅうしょを つくる（`Page.addScriptToEvaluateOnNewDocument` で `WARPIX_MOVE` を いれる）。

1. ふるい じゅうしょで PRESS START の あとに さそい、「きろくごと ひっこす」で あたらしい じゅうしょへ。ハイスコア・実績が うつり、URL に じゅもんが のこらず、`warpix-moved-out` は もってこない。あいさつ「ひっこし、おつかれさま」。もどると「もう あたらしい おうちに いるよ」
2. とどかない じゅうしょ・404 では さそわない
3. もう きろくが ある ブラウザでは きいてから（「いまの まま」で かわらない、「いれかえる」で いれかわる）。こわれた じゅもんでは かわらず、ボタンも ださない
