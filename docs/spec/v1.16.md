## ランキングと名前入れ

- **いつ**：ゲームオーバーで、点が 0 より大きく、ベスト 5 に入るとき（5 人未満なら必ず）。デモプレイでは出ない
- **画面**：NEW RECORD!・点数・ENTER NAME。3 文字と END。文字は A〜Z・0〜9・`.` `-` `!`・空白（`_` で表示）
- **最初の名前**：前に入れた名前（はじめては `PIX`）
- **キーボード**：↑↓（W/S）で文字、←→ で場所、Enter/スペースで次へ、END で Enter すると決定。文字キーを打つとその文字が入って次へ。Backspace で 1 つ戻る
- **タッチ**：文字の上半分（▲）で次の文字、下半分（▼）で前の文字。END をタップで決定
- **コントローラー**：十字キーで文字と場所、A で次へ・決定
- **とちゅうで閉じる**（Esc・✕）：そのときの名前で のこす
- **決定のあと**：GAME OVER と HIGH SCORES（順位・名前・点数）。入ったばかりの行は点滅。ランキングが 1 つでもあれば、ゲームオーバーのたびに表示（デモプレイでも）
- **イベント**：`game-rank { rank, name, score }`。実績「なまえを きざめ」、日記「ミニゲームの ランキングで ◯いに なった！（名前）」
- **保存**：`warpix-ranking`（`{ n: 名前, s: 点数, w: ウェーブ }` を 5 つまで）、`warpix-rank-name`（前の名前）。このブラウザだけ
