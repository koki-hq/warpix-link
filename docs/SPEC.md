# warpix-link 仕様メモ（v1.2）

ページが「何を・いつ・どれだけ」するかをまとめたメモです。
見た目の決まりごとは [THEME.md](THEME.md)、遊び方とカスタマイズ方法は [README](../README.md) にあります。
数値を変えたら、このメモも合わせて直してください。

## 構成

ビルドなし。`index.html` が次の3つのスクリプトを順に読み込みます（ES モジュールではなく普通の `<script>`。`file://` で開いても動かすため）。

| ファイル | 役割 |
| --- | --- |
| `script.js` | 土台。アイコン、サウンド、星、スコア、ピクセ、ワープゾーン、UFO、PRESS START |
| `game.js` | ミニゲーム PIXE INVADERS |
| `extras.js` | 実績、隠しコマンド、マザーシップ、流れ星、居眠り、行き先紹介、キラキラ、コンソール |

3つのファイルはトップレベルの `const`（`sound`、`stars`、`score`、`npc`、`game` など）を共有しています。
`script.js` はできごとを**イベントバス**で知らせ、`game.js` / `extras.js` は `on(名前, 関数)` で受け取ります。土台に手を入れずに遊び要素を足すための仕組みです。

### イベント一覧

| イベント | いつ | 中身 |
| --- | --- | --- |
| `boot` | PRESS START 後、ページが立ち上がったとき | なし |
| `warp` | リンクボタンを押したとき | `{ icon }`（`youtube` など。ワープゾーンは `key`） |
| `poke` | ピクセをつついたとき | `{ streak }`（連続回数） |
| `secret` | ワープゾーンが開いたとき | なし |
| `konami` | コナミコマンドを入力したとき | なし |
| `ufo-down` | UFO を撃ち落としたとき | なし |
| `score` | 点が入ったとき | `{ value, mult }`（合計点、コンボ倍率） |
| `bgm` | BGM ボタンを押したとき | `{ on }` |
| `game-start` | ミニゲームを開いたとき | なし |
| `game-wave` | ミニゲームでウェーブをクリアしたとき | `{ wave }` |
| `game-over` | ミニゲームの点がページに入るとき | `{ score, wave }` |

## 起動の流れ

| 時間（クリック後） | できごと |
| --- | --- |
| 0 秒 | 起動ジングル。BGM 予約（0.8 秒後に開始） |
| 0〜0.45 秒 | PRESS START 画面が3回点滅して消える |
| 0.45 秒 | `boot`。タイトルが落ちてくる |
| +0.5 秒 | サブタイトル・HUD・ピクセ・フッターが出る |
| +0.6 秒〜 | リンクボタンが 0.12 秒おきに1つずつ出る |
| +1.6 秒 | ピクセのあいさつ開始（3行。ウィンドウをクリックで次へ） |
| +15 秒 | 最初の UFO |
| +25 秒 | 最初の流れ星 |

**ホバーの扱い**：スタートをクリックした位置にボタンが出てくると、マウスを動かしていなくてもホバー扱いになります。そのため、行き先紹介はあいさつを言い終えるまで出さず、ホバー音はスタート後にマウスが実際に動くまで鳴らしません。

## スコア

| 行動 | 点 |
| --- | --- |
| リンクを押す | 100 |
| ピクセをつつく | 10 |
| ピクセの雨をつかまえる | 50 |
| マザーシップに当てる | 200（1発ごと） |
| 流れ星をつかまえる | 500 |
| UFO を撃ち落とす | 1,000 |
| ワープゾーンが開く | 5,000 |
| マザーシップを撃沈 | 10,000 |
| ミニゲーム | ゲームの点をそのまま加算 |

- **コンボ**：前の得点から 1.5 秒以内に点が入るとコンボが続く。倍率は「1 + コンボ数 ÷ 5（切り捨て）」で、最大 x4。ミニゲームの点を加算するときも倍率がかかる
- **表示**：6 桁（最大 999999）。点が入ると `+100` や `+400 x4` がカクカク浮かぶ
- **ハイスコア**：ブラウザに保存。PRESS START 画面にも出る

## ピクセ

- **あいさつ**：時間帯で1行目が変わる（0〜5時「よふかし？」/ 5〜10時 おはよう / 10〜17時 こんにちは / 17〜24時 こんばんは）
- **文字送り**：45ms に1文字。2文字ごとに小さな音
- **まばたき**：3.2 秒ごとに 0.15 秒
- **つつく**：ジャンプ＋コイン音＋10点。1.5 秒以内に続けてつつくと連続回数が増える
  - 1〜4回目：ランダムなひとこと（直前と同じものは出さない）
  - 5回目：「むずむず してきた」
  - 10回目：ワープゾーンが開く
- **行き先紹介**：あいさつを言い終えたあと、リンクにカーソルを乗せる（またはフォーカスする）と紹介する。同じリンクで2回続けては言わない
- **居眠り**：40 秒間なにも操作がないと寝る（目を閉じて「Z z z」）。マウス・キー・タッチ・ホイールのどれかで起きる。ミニゲーム中とタブが裏にあるときは寝ない

## 空のできごと

| | 出るタイミング | 動き | 倒すと |
| --- | --- | --- | --- |
| UFO | 最初 15 秒後、以降 20〜40 秒ごと | 9 秒で画面を横切る（90 コマ） | 1,000 点 |
| マザーシップ | UFO を 3 機落とすごと（予告から 3 秒後） | 16 秒で横切る（160 コマ）。HP 10 | 1発 200 点、撃沈 10,000 点 |
| 流れ星 | 最初 25 秒後、以降 25〜50 秒ごと | 1.6 秒で右上から左下へ | 500 点 |

- 「動きを減らす」設定のときは UFO と流れ星が来ないので、マザーシップも来ません
- タブが裏にあるときは、その回の UFO と流れ星をスキップします。流れ星はミニゲーム中もスキップします

## ワープゾーン

- **開き方**：コナミコマンド（↑↑↓↓←→←→BA）、またはピクセを 10 回連続でつつく
- **開くと**：パワーアップ音、星がワープ、タイトルの影がチカチカ、ピンクの WARP ZONE ボタンが出る、5,000 点
- 1回開いたらそのページを開いている間は開いたまま（保存はしない）

## 隠しコマンド

キーボードで直接打つ（最後に打った 12 文字の末尾で判定）か、実績画面の CHEAT CODE 欄に入力します。
入力欄やダイアログの中で打った文字と、ミニゲーム中の入力は数えません。

| 単語 | 効果 | 続く時間 |
| --- | --- | --- |
| `gameboy` | 配色をゲームボーイの4色に。もう一度で戻る | 戻すまで |
| `party` | BGM 1.6 倍速、星がカラフル、背景の色が変わる、ピクセが 0.4 秒ごとにジャンプ | 10 秒 |
| `pixe` | ピクセが 24 匹ふってくる（2〜4 秒で落下） | 落ちきるまで |
| `warp` | ハイパーワープ（星が 3 秒間加速）＋画面ゆれ | 3 秒 |
| `help` | まだ取っていない実績のヒントをランダムに1つ | — |
| `invaders` | ミニゲームを開く | — |

コンソールで `pixe()` を呼ぶと、ピクセがコマンド一覧を教えてくれます（実績「ハッカー」）。

## ミニゲーム PIXE INVADERS

- **入り口**：フッターの INSERT COIN、またはコマンド `invaders`
- **画面**：160×144 で描いて、画面に収まる最大の整数倍に拡大。60fps 固定で更新
- **操作**：← → / A D、またはドラッグ（タップした位置へ向かう）。ショットは自動（16 フレームごと、画面に最大 3 発）
- **自機**：ライフ 3。被弾後 90 フレーム無敵（点滅）
- **敵**：6 列 × 3 段。端に着くと 4px 下がって折り返す。残りが少ないほど、ウェーブが進むほど速い
  - 行進の間隔（フレーム）＝ max(3, 28 − (18 − 残り数) × 1.4 − ウェーブ × 2)
  - 1歩ごとに「0.25 + ウェーブ × 0.05」の確率で、どれか1体が弾を撃つ
- **点**：上の段から 30 / 20 / 10 点 × ウェーブ数。ウェーブクリアで 100 × ウェーブ数
- **終わり**：ライフが 0、または敵が自機の高さまで来たらゲームオーバー。タップか Space / Enter でリトライ
- **閉じる**：✕ ボタンか Esc。途中で閉じても、そこまでの点はページに入る
- タブが裏に回ると一時停止し、戻ると続きから

## サウンド

- すべて Web Audio API で生成（音源ファイルなし）。PRESS START を押すまで何も鳴らさない
- **BGM**：140 BPM、Am → F → C → G の 4 小節ループ。メロディ（矩形波）、ベース（三角波）、裏拍のハイハット（ノイズ）
- タブが裏に回ると音全体を一時停止し、タブ名を「PAUSE ⏸ warpix-link」にする

## ブラウザに保存するもの

`localStorage` に保存します。読み書きに失敗しても（プライベートモードなど）ページは普通に動きます。

| キー | 中身 |
| --- | --- |
| `warpix-bgm` | BGM の ON / OFF（`"on"` / `"off"`） |
| `warpix-hi` | ハイスコア |
| `warpix-achievements` | 取った実績の ID の配列 |
| `warpix-visited` | 押したことのあるリンクの配列（せかい いっしゅう用） |
| `warpix-pokes` | ピクセをつついた通算回数 |

全部リセットしたいときは、開発者ツールのコンソールで `localStorage.clear()` を実行します。

## 動きを減らす設定のとき

OS で「視差効果を減らす / アニメーションを減らす」を設定していると、次のように変わります。

- 星は止まった状態で表示。ワープしても加速しない
- 登場アニメーションはすぐ終わる。点滅・ゆれ・ジャンプ・居眠りの Z もなし
- UFO と流れ星は来ない（なのでマザーシップも来ない）。ピクセの雨、キラキラも出ない
- 音とゲーム（ミニゲーム、実績、コマンド）はそのまま使える
